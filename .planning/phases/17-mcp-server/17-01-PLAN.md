## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client -> /api/mcp | AI agent sends tool calls with Bearer token; untrusted input |
| MCP tools -> service layer | Validated params passed to existing services with userId scoping |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Spoofing | MCP auth | mitigate | withMcpAuth required:true + verifyMcpToken validates API key hash against DB; revoked keys rejected |
| T-17-02 | Tampering | Tool inputs | mitigate | Zod schemas on all tool inputSchema; UUID validation on projectId; bounds on slideCount/slideIndex |
| T-17-03 | Information Disclosure | Cross-user data | mitigate | All service calls pass userId from auth; services filter by user_id in DB queries |
| T-17-04 | Elevation of Privilege | Admin client misuse | mitigate | adminClient passed only to service functions that already enforce user_id filtering |
| T-17-05 | Denial of Service | Render-heavy tools | accept | maxDuration=60 matches REST endpoints; rate limiting applied via existing API key infrastructure at transport level |
| T-17-06 | Tampering | backgroundUrl injection | mitigate | Zod z.string().url() validates URL format; editor service already restricts to https:// URLs |
</threat_model>
