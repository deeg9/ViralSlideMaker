The single template-by-id resolver (src/lib/render/templates/index.ts L260-262):
```typescript
export function getTemplate(id: string): SlideTemplate {
  return templates.find((t) => t.id === id) ?? templates[0]
}
```
There is NO separate `resolveTemplate` in this file — `resolveTemplate` (async, DB-aware) lives in `registry.ts` and delegates code-template lookup back to `getTemplate`. One line in `getTemplate()` covers every render/publish/fork/download path.

Target shape (PATTERNS.md § 1 — copy this exact form):
```typescript
export function getTemplate(id: string): SlideTemplate {
  // Phase 89 (BKSHELVE-07): 'brand-kit' is the shelved-feature sentinel.
  // Legacy projects saved against the removed brand-kit feature carry
  // template_id === 'brand-kit'; resolve it to a live default template.
  const resolvedId = id === 'brand-kit' ? 'news-oracle' : id
  return templates.find((t) => t.id === resolvedId) ?? templates[0]
}
```
