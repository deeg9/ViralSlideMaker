### Existing test file structure
The existing `template-picker.test.tsx` (Phase 48 TPLTHUMB-02) has these test cases:
- "renders exactly 8 SlidePreview tiles for the templates list when brandKit is null"
- "renders exactly 9 SlidePreview tiles when brandKit is configured (8 templates + brand-kit tile)"
- "shows brand-kit empty-state link (not a SlidePreview) when brandKit is null"
- "renders a 'Selected' indicator on the active template tile"

The schema invariant assertion (`expect(templates.length).toBe(8)`) was a deliberate guard against drift.

### Phase 56 changes
Phase 56-03 added 3 new templates (editorial-serif, notes-app-chic, brutalist-grid). The `templates` array now has 11 entries.

The test must:
1. Update existing `expect(templates.length).toBe(8)` → `expect(templates.length).toBe(11)`
2. Update test description text from "exactly 8 SlidePreview tiles" → "exactly 11 SlidePreview tiles"
3. Update brand-kit-configured test from "9 SlidePreview tiles (8 + 1)" → "12 SlidePreview tiles (11 + 1)"
4. Add a new test specifically asserting that the 3 new templates each render as `<SlidePreview>` (not swatch fallback) — checked via `data-template-id` attribute or similar on each tile

### Approach
The existing test counts SlidePreview instances by `getAllByTestId('slide-preview')`. To assert each NEW template specifically renders, the new test can:

Option A (simpler): Render the picker, query for each of the 3 new template IDs as a separate `screen.getByText('Editorial Serif')`, `getByText('Notes App Chic')`, `getByText('Brutalist Grid')` to confirm the tile name appears.

Option B (more robust): Add a `data-template-id={template.id}` attribute to the picker tile root in `template-picker.tsx`, then assert `screen.getByTestId(`template-tile-${id}`)` for each new template.

Option B is cleaner and provides a stable test selector. However, it requires modifying the picker component, which is out of scope for "no UI changes." Option A is sufficient for TPL-08.

**Decision: Option A** — query by template name (which appears in each tile per existing TemplatePicker rendering). No picker component changes.
