# Plan 84-01: LayoutRecipe Type Model

## Objective

Land the `LayoutRecipe` TypeScript type — a role-keyed (cover / body / cta)
set of slide archetypes capturing per-slide layout mode, caption-card
geometry, hook placement, accent rhythm, and optional accessory-label slots.
Mirrors the `StyleSpec` type architecture
(`src/lib/types/style-spec.ts` + `style-spec-archetypes.ts`).

## Context

- This is the load-bearing type contract. The validator (Plan 84-02) and
  extraction (Plan 84-03) both import from this module.
- **Closed-enum invariant (load-bearing):** every string field is an
  `... as const` tuple defined ONCE in this module. Continuous geometry
  stays numeric (validated ranges in the validator, not bucketed).
- The role layout-mode discriminator REUSES the existing 8-value
  `SlideArchetype` enum from `src/lib/types/style-spec-archetypes.ts` — do
  NOT invent a new archetype set (CONTEXT.md locked decision).
- Caption-card `position` reuses the `'bottom' | 'top'` concept from
  `SlideStyleOverrides.caption_bar_position` — declare it as a local
  closed-enum tuple `CAPTION_POSITIONS = ['bottom','top']` (the source
  field is an inline union, not an exported tuple, so a local tuple is the
  single-source-of-truth definition for the recipe).
- Hook `text_align` reuses the `'left' | 'center' | 'right'` triple
  (`SlideStyleOverrides.text_align`) — declare as `RECIPE_TEXT_ALIGNS`.
- `schema_version: 1` literal — forward-compat (StyleSpec `schema_version: 2`
  precedent).

   ```ts
   export type RecipeRole = (typeof RECIPE_ROLES)[number]

   export const HOOK_POSITION_BANDS = ['top', 'upper', 'center', 'lower', 'bottom'] as const
   export type HookPositionBand = (typeof HOOK_POSITION_BANDS)[number]

   export const HOOK_FONT_SIZE_BANDS = ['sm', 'md', 'lg', 'xl'] as const
   export type HookFontSizeBand = (typeof HOOK_FONT_SIZE_BANDS)[number]

   export const RECIPE_TEXT_ALIGNS = ['left', 'center', 'right'] as const
   export type RecipeTextAlign = (typeof RECIPE_TEXT_ALIGNS)[number]

   export const CAPTION_POSITIONS = ['bottom', 'top'] as const
   export type CaptionPosition = (typeof CAPTION_POSITIONS)[number]

   export const ACCENT_CADENCES = ['none', 'sparse', 'every-other', 'frequent'] as const
   export type AccentCadence = (typeof ACCENT_CADENCES)[number]

   export const ACCESSORY_LABEL_BANDS = ['top', 'upper', 'lower', 'bottom'] as const
   export type AccessoryLabelBand = (typeof ACCESSORY_LABEL_BANDS)[number]
   ```

5. Interfaces:
   ```ts
   /** Caption-card geometry — numeric with validator-clamped ranges.
       Mirrors SlideStyleOverrides.caption_bar_{enabled,x,y,width,
       height_pct(=caption_bar_height_pct),blend_pct,opacity,position}. */
   export interface CaptionCardGeometry {
     enabled: boolean
     x: number          // 0..100, left edge percent
     y: number          // 0..100, top edge percent
     width: number      // 0..100, width percent
     height_pct: number // 0..100
     blend_pct: number  // 0..50, edge-blend percent
     opacity: number    // 0..1
     position: CaptionPosition
   }

   /** Hook placement — closed-enum bands + reused text_align. */
   export interface HookPlacement {
     position_band: HookPositionBand
     font_size_band: HookFontSizeBand
     text_align: RecipeTextAlign
   }

   /** Optional accessory-label slot (Phase 82 Slide.accessory_label). */
   export interface AccessoryLabelSlot {
     enabled: boolean
     position_band: AccessoryLabelBand
   }

   /** A single role's layout description. `layout_mode` reuses the 8-value
       SlideArchetype enum — do NOT introduce a new archetype set. */
   export interface RoleLayout {
     layout_mode: SlideArchetype
     caption_card?: CaptionCardGeometry
     hook?: HookPlacement
     accessory_label?: AccessoryLabelSlot
   }

   /** Top-level recipe. `roles` is a partial keyset — a role may be omitted
       for short carousels (skip-emit; never synthesized). */
   export interface LayoutRecipe {
     schema_version: LayoutRecipeVersion
     accent_cadence: AccentCadence
     roles: {
       cover?: RoleLayout
       body?: RoleLayout
       cta?: RoleLayout
     }
   }
   ```
