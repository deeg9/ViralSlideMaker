# Plan 84-02: parseLayoutRecipeSafe Validator

## Objective

Land `parseLayoutRecipeSafe` — the zod validation firewall for the
`LayoutRecipe` model, mirroring `parseStyleSpecSafe` in
`src/lib/validators/style-spec.ts`. Closed-enum silent-drop, numeric range
clamp, unknown-key stripping.

## Context

- Mirror `src/lib/validators/style-spec.ts` exactly: `catchall(z.never())`
  on every nested object, a pre-clean walker that strips unknowns + emits
  silent-drop counter events, a final `safeParse`.
- This phase reuses `createSilentDropCounter` from
  `src/lib/validators/silent-drop-counter.ts` — its `SilentDropReason`
  union already includes `unknown_enum_value`, `unknown_field`,
  `parse_error`. **Add a `range_clamp` reason** to that union (numeric
  geometry clamp is a new drop kind; the union is closed by contract).
- Caption-card geometry numeric ranges (clamp, do not reject):
  `x` [0,100], `y` [0,100], `width` [0,100], `height_pct` [0,100],
  `blend_pct` [0,50], `opacity` [0,1].
- The recipe validates `layout_mode` via `z.enum(SLIDE_ARCHETYPES)`. An
  unrecognized/absent `layout_mode` falls back to
  `DEFAULT_FALLBACK_ARCHETYPE` at the pre-clean walker.
- A role may be entirely absent — the validator must accept a recipe with
  `roles: {}` or any subset; never error on a missing role.

<action>
Create `src/lib/validators/layout-recipe.ts`:

1. Header comment documenting the firewall contract (mirror style-spec.ts
   header — closed-enum silent-drop + prompt-injection defense).

2. Imports: `z` from zod; `LayoutRecipe`, `LAYOUT_RECIPE_VERSION`,
   `RECIPE_ROLES`, `HOOK_POSITION_BANDS`, `HOOK_FONT_SIZE_BANDS`,
   `RECIPE_TEXT_ALIGNS`, `CAPTION_POSITIONS`, `ACCENT_CADENCES`,
   `ACCESSORY_LABEL_BANDS` from `@/lib/types/layout-recipe`;
   `SLIDE_ARCHETYPES`, `DEFAULT_FALLBACK_ARCHETYPE` from
   `@/lib/types/style-spec-archetypes`; `createSilentDropCounter`,
   `SilentDropCounter` from `./silent-drop-counter`.

3. A `clampNumber(value, min, max, field, counter)` helper: if `value` is
   not a finite number → return the range midpoint `(min+max)/2` and emit a
   `parse_error` counter event; if outside `[min,max]` → clamp to the
   nearest bound and emit a `range_clamp` counter event; else return the
   value as-is. Pure / deterministic.

4. Zod schemas, every `z.object(...)` terminated with `.catchall(z.never())`:
   - `CaptionCardGeometryZ`: `enabled` z.boolean(), `x` / `y` / `width` /
     `height_pct` / `blend_pct` / `opacity` z.number(), `position`
     z.enum(CAPTION_POSITIONS). (Clamping happens in the walker BEFORE
     safeParse — the schema only type-checks.)
   - `HookPlacementZ`: `position_band` z.enum(HOOK_POSITION_BANDS),
     `font_size_band` z.enum(HOOK_FONT_SIZE_BANDS), `text_align`
     z.enum(RECIPE_TEXT_ALIGNS).
   - `AccessoryLabelSlotZ`: `enabled` z.boolean(), `position_band`
     z.enum(ACCESSORY_LABEL_BANDS).
   - `RoleLayoutZ`: `layout_mode` z.enum(SLIDE_ARCHETYPES), `caption_card`
     CaptionCardGeometryZ.optional(), `hook` HookPlacementZ.optional(),
     `accessory_label` AccessoryLabelSlotZ.optional().
   - `LayoutRecipeSchema`: `schema_version` z.literal(LAYOUT_RECIPE_VERSION),
     `accent_cadence` z.enum(ACCENT_CADENCES), `roles` z.object({ cover:
     RoleLayoutZ.optional(), body: RoleLayoutZ.optional(), cta:
     RoleLayoutZ.optional() }).catchall(z.never()).

5. A pre-clean walker `cleanRecipe(input, counter)`:
   - Non-object input → emit `parse_error`, return a sentinel that makes
     the caller produce `ok:false`.
   - Strip unknown top-level keys (anything not `schema_version` /
     `accent_cadence` / `roles`) → emit `unknown_field` per key.
   - Force `schema_version` to `LAYOUT_RECIPE_VERSION`.
   - `accent_cadence`: if not a string in `ACCENT_CADENCES` → emit
     `unknown_enum_value`, default to `'none'`.
   - For each of `RECIPE_ROLES`: if the role object is present in
     `input.roles`, clean it:
     - `layout_mode`: if not in `SLIDE_ARCHETYPES` → emit
       `unknown_enum_value`, set to `DEFAULT_FALLBACK_ARCHETYPE`.
     - `caption_card` (if present): clamp `x` [0,100], `y` [0,100],
       `width` [0,100], `height_pct` [0,100], `blend_pct` [0,50],
       `opacity` [0,1] via `clampNumber`; if `position` not in
       `CAPTION_POSITIONS` → emit `unknown_enum_value`, set `'bottom'`;
       coerce non-boolean `enabled` → `false` with an `unknown_enum_value`
       event.
     - `hook` (if present): for each of `position_band` / `font_size_band`
       / `text_align`, if the value is not in its tuple → emit
       `unknown_enum_value` and OMIT that sub-field (zod `.optional()` on
       the field is not used — instead drop the whole `hook` object only
       if it ends up empty; otherwise keep the valid sub-fields). Simplest
       compliant approach: if ANY of the 3 hook fields is invalid, emit the
       event(s) and omit the entire `hook` object (skip-emit).
     - `accessory_label` (if present): if `position_band` not in
       `ACCESSORY_LABEL_BANDS` → emit `unknown_enum_value` and omit
       `accessory_label`; coerce non-boolean `enabled` → `false`.
     - Strip unknown keys inside each role object and each sub-object →
       `unknown_field` events.
     - A role absent from `input.roles` stays absent (skip-emit) — never
       synthesize a missing role.

6. Public entry point:
   ```ts
   export type ParseLayoutRecipeResult =
     | { ok: true; recipe: LayoutRecipe; counter: SilentDropCounter }
     | { ok: false; counter: SilentDropCounter; error: z.ZodError }

   export function parseLayoutRecipeSafe(
     input: unknown,
     opts?: { counter?: SilentDropCounter },
   ): ParseLayoutRecipeResult
   ```
   Run the walker; on non-object input return `ok:false` with a synthetic
   `z.ZodError`. Otherwise `LayoutRecipeSchema.safeParse(cleaned)`; on
   failure emit `parse_error` and return `ok:false` with `result.error`;
   on success return `ok:true` with `recipe: result.data as LayoutRecipe`.
</action>
