<objective>
Surface the "from references" provenance to the user across two locations:

1. **Dashboard project list** — a small "From references" badge on each ProjectCard whose project.style_spec is non-null. Visual differentiator: the user can immediately see which projects came from the new style-from-reference flow vs. the legacy template+topic flow. EDITOR-02.
