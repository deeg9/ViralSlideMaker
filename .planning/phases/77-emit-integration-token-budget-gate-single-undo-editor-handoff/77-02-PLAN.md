- **mode: 'ai-copy'** — user provides topic; Gemini generates new slide copy in the spec's voice (spec.voice_note REPLACES template.aiVoiceNote when both present per EMIT-05)
- **mode: 'user-copy'** — user provides per-slide copy strings; Gemini structures into Slide segments + applies role + decoration choices (no copy generation)

The 12K-token CI gate (EMIT-06) prevents prompt-budget regression — assembles a worst-case prompt (system_prompt + max-StyleSpec + max-brand-kit + worst-case topic) and asserts it fits Gemini 2.5 Flash headroom.

Single reducer dispatch + single pushHistory (EMIT-10) — the regenerated slides flow through the existing SET_SLIDES action, which is already a single-pushHistory action (verified in src/lib/editor/editor-reducer.ts:300). So Cmd+Z restores the pre-generation state in one step. This is achieved by routing the regenerated project the same way today's Gemini emit lands — no new editor wiring.
