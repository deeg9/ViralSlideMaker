<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Configure Vercel environment variables and Stripe webhook</name>
  <what-built>Complete environment variable documentation</what-built>
  <how-to-verify>
    The user must complete these steps manually:

    **Step 1: Set Vercel Environment Variables**
    1. Go to https://vercel.com → ViralSlideMaker project → Settings → Environment Variables
    2. Add ALL variables from `.env.local.example` with production values:
       - Copy Supabase keys from your Supabase dashboard
       - Copy Gemini API key (same as dev)
       - Copy Pexels API key (same as dev)
       - For Stripe: use LIVE keys (sk_live_, pk_live_) or keep test keys for now
       - Set `NEXT_PUBLIC_APP_URL` to `https://viralslidemaker.com`
       - Leave `STRIPE_WEBHOOK_SECRET` empty for now (set in step 2)

    **Step 2: Create Stripe Production Webhook**
    1. Go to Stripe Dashboard → Developers → Webhooks
    2. Click "Add endpoint"
    3. URL: `https://viralslidemaker.com/api/webhooks/stripe`
    4. Select events:
       - `checkout.session.completed`
       - `customer.subscription.updated`
       - `customer.subscription.deleted`
       - `invoice.paid`
       - `invoice.payment_failed`
    5. Click "Add endpoint"
    6. Copy the signing secret (whsec_...)
    7. Go back to Vercel and set `STRIPE_WEBHOOK_SECRET` to this value

    **Step 3: Redeploy**
    1. Trigger a new deployment in Vercel (push a commit or click "Redeploy")
    2. Wait for deployment to complete

    **Step 4: Verify**
    1. Visit https://viralslidemaker.com — should load the app
    2. Try logging in
    3. Try creating a carousel
    4. Check Stripe webhook logs for any delivery errors
  </how-to-verify>
  <resume-signal>Type "deployed" once you've completed the steps above</resume-signal>
</task>
