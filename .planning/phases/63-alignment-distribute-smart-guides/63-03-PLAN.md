<objective>
Wave B core — pure snap math layer. This plan ships the algorithm; Plan 63-04 wires it into drag handlers.

1. `buildSnapIndex(slide, excludeIds)` — walks all elements (text_boxes ∪ custom_images ∪ watermark) NOT in excludeIds, emits sorted xEdges + yEdges arrays. Includes canvas edges (0, 540, 1080 / 0, 960, 1920).
2. `findNearestSnap(value, sortedEdges, threshold)` — O(log N) binary search via lower_bound + neighbor check.
3. `snapWithHysteresis(query, sortedEdges, prevWasSnapped)` — asymmetric threshold state machine: enter at ≤5, exit at >7 (SNAP-10). Returns { snapped: boolean, snappedTo: number | null, delta: number, nextWasSnapped: number | null }.
4. Performance bench fixture verifying <2ms per query at N=30 elements (PERF-05).

**Why parallel to Plan 63-01 (also Wave 1):** Independent code surface — 63-01 is alignment math; 63-03 is snap math. Zero file overlap. They're WAVE 1 because both have no upstream phase deps within Phase 63.

**Critical algorithmic correctness:** binary search lower_bound MUST handle duplicate edges (multiple elements at the same x position — common when alignment has been applied). Test SI-15 pins this. Hysteresis state must be PER-AXIS (separate wasSnappedX and wasSnappedY) because one axis can be snapped while the other is free (Test SI-20 pins).

**Reachability:** Plan 63-04 is the sole consumer; this plan ships against a documented signature contract that Plan 63-04 will wire from slide-preview.tsx onDragStart / onDrag / onDragStop.

Purpose: Replace the existing `useAlignmentGuides` (O(N×M) per pointer-move at N=6 — fine; at N=30 — sluggish) with a sorted-edge-array implementation. Pure module is testable without React.

Output: 1 new pure module + 30+ unit tests + 1 performance bench. ~550 LOC.

    4. `buildSnapIndex(slide: Slide, excludeIds: Set<string>, canvasW = REF_WIDTH, canvasH = REF_HEIGHT): SnapIndex`:
       - Init xEntries + yEntries with canvas edges (kind='canvas-edge' for 0/W and kind='canvas-center' for W/2; sourceId='canvas').
       - Walk text_boxes: skip if id in excludeIds; skip if anchor !== 'custom'; convert position.x/y/width from % to REF px via REF_WIDTH/REF_HEIGHT multiply; push 3 X-edges (left/center-h/right) + 3 Y-edges (top/center-v/bottom).        - Sort xEntries by pos ASCENDING; sort yEntries by pos ASCENDING (stable sort — Array.prototype.sort).
       - Return { xEdges: xEntries, yEdges: yEntries }.

    5. `findNearestSnap(value: number, sortedEdges: EdgeEntry[], threshold: number): SnapQueryResult`:
       - If sortedEdges.length === 0: return { snappedTo: null, delta: 0 }.
       - Binary search lower_bound for `value`:
         ```typescript
         let lo = 0, hi = sortedEdges.length
         while (lo < hi) {
           const mid = (lo + hi) >>> 1
           if (sortedEdges[mid].pos < value) lo = mid + 1
           else hi = mid
         }
         // lo is now the first index where pos >= value (or length if all are below)
         ```
       - Check candidates at indices lo-1 and lo (the two neighbors of `value` in sort order):
         ```typescript
         let bestPos: number | null = null
         let bestAbsDelta = Infinity
         for (const idx of [lo - 1, lo]) {
           if (idx < 0 || idx >= sortedEdges.length) continue
           const ed = sortedEdges[idx]
           const d = ed.pos - value
           const ad = Math.abs(d)
           if (ad <= threshold && ad < bestAbsDelta) { bestAbsDelta = ad; bestPos = ed.pos }
         }
         ```
       - Return { snappedTo: bestPos, delta: bestPos === null ? 0 : bestPos - value }.
       - Complexity: O(log N) for the binary search + O(1) for the 2-neighbor check = O(log N).

    6. `snapWithHysteresis(value: number, sortedEdges: EdgeEntry[], prevWasSnapped: number | null): HysteresisResult`:
       - If `prevWasSnapped !== null`:
         - Find the entry at prevWasSnapped (cheap — caller already had it last frame; we trust the state).
         - Compute delta = prevWasSnapped - value.
         - If |delta| <= SNAP_THRESHOLD_EXIT: return { snapped: true, snappedTo: prevWasSnapped, delta, nextWasSnapped: prevWasSnapped }. // hold zone
         - Else: fall through to fresh search (the user has dragged out of the hold zone).
       - Fresh search: const r = findNearestSnap(value, sortedEdges, SNAP_THRESHOLD_ENTER).
         - If r.snappedTo !== null: return { snapped: true, snappedTo: r.snappedTo, delta: r.delta, nextWasSnapped: r.snappedTo }.
         - Else: return { snapped: false, snappedTo: null, delta: 0, nextWasSnapped: null }.
       - JSDoc note: "Caller MUST track X and Y hysteresis state separately — pass them as separate calls. Bundling X+Y in one helper would force a 2D state machine; the per-axis design honors PITFALL-5.2 (the deadband applies independently per axis)."
