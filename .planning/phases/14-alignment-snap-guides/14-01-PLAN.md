Create `src/hooks/use-alignment-guides.ts` exporting a `useAlignmentGuides` hook.

**Interface:**
```typescript
interface TextBox {
  id: string           // 'hook' | 'body'
  x: number            // reference pixels (0-1080)
  y: number            // reference pixels (0-1920)
  width: number         // reference pixels
  height: number        // reference pixels (from getBoundingClientRect / scale)
}

interface GuideLine {
  orientation: 'horizontal' | 'vertical'
  position: number     // reference pixels
}

interface SnapResult {
  snappedX: number     // reference pixels (adjusted position)
  snappedY: number     // reference pixels (adjusted position)
  guides: GuideLine[]  // active guide lines to render
}

function useAlignmentGuides(): {
  calculateSnap: (dragging: TextBox, others: TextBox[]) => SnapResult
  activeGuides: GuideLine[]
  clearGuides: () => void
}
```

**Snap threshold:** 10 reference pixels (approximately 5 screen pixels at typical scale, since the canvas is ~540px wide on desktop = scale ~0.5, so 10 ref px = ~5 screen px).

**Guide sources (all in reference pixels):**
1. **Canvas center:** vertical at x=540 (REF_WIDTH/2), horizontal at y=960 (REF_HEIGHT/2)
2. **Other text box edges:** For each non-dragging text box, compute: left edge (x), right edge (x + width), horizontal center (x + width/2), top edge (y), bottom edge (y + height), vertical center (y + height/2)

**Snap logic for each axis:**
- Compare the dragging box's left edge, right edge, and center against each guide source
- If any edge/center is within threshold of a guide source, snap that edge/center to align
- Return the adjusted position and the matching guide lines

**State:** Use `useState` for `activeGuides: GuideLine[]`. `calculateSnap` updates activeGuides and returns SnapResult. `clearGuides` sets activeGuides to empty array (call on drag end).

Do NOT persist guides to any data model -- they are purely ephemeral visual feedback.

**2. Add `onDrag` callback to both Rnd components:**
Currently only `onDragStop` is used. Add `onDrag` to compute snap guides during drag. The `onDrag` callback receives `(e, data)` where `data.x` and `data.y` are in reference pixels (react-rnd handles scale).

For the hook text Rnd:
```typescript
onDrag={(_e, data) => {
  const dragging: TextBox = {
    id: 'hook',
    x: data.x,
    y: data.y,
    width: hookWidthPx,
    height: hookRef.current?.getBoundingClientRect().height / scale || 200,
  }
  const others: TextBox[] = slide.body_text ? [{
    id: 'body',
    x: bodyPixels.x,
    y: bodyPixels.y,
    width: bodyWidthPx,
    height: bodyRef.current?.getBoundingClientRect().height / scale || 200,
  }] : []
  const result = calculateSnap(dragging, others)
  // Snap position by mutating data (react-rnd supports this)
  data.x = result.snappedX
  data.y = result.snappedY
}}
```

Do the equivalent for the body text Rnd (swap hook/body in dragging vs others).

Add `onDragStop` modification: after the existing position dispatch, call `clearGuides()`.

**3. Add refs to measure text box heights:**
Add `useRef<HTMLDivElement>(null)` for hook and body text boxes. Attach refs to the Rnd components via the inner div wrapper. Use `ref.current?.getBoundingClientRect().height / scale` to get reference-pixel height for snap calculations. Fallback to 200 if ref is null.

**4. Render guide line overlay (inside the editable return, after the Rnd components, before slide number badge):**
```tsx
{activeGuides.map((guide, i) => (
  <div
    key={i}
    data-testid="alignment-guide"
    style={{
      position: 'absolute',
      [guide.orientation === 'vertical' ? 'left' : 'top']: guide.position,
      [guide.orientation === 'vertical' ? 'top' : 'left']: 0,
      [guide.orientation === 'vertical' ? 'width' : 'height']: 0,
      [guide.orientation === 'vertical' ? 'height' : 'width']: guide.orientation === 'vertical' ? REF_HEIGHT : REF_WIDTH,

      zIndex: 50,
      pointerEvents: 'none',
    }}
  />
))}
```

Guide lines are dashed, subtle red (matches the app's red-tinted design language from the `#3d0000` color scheme), and use `pointerEvents: 'none'` so they don't interfere with drag.
