## How to use this doc

- Each section enumerates a gate family (PTF / PCL / PRA / PRS / LP-NEW / SWEEP-PICK / DEPS / MIGR / AI-advisory).
- Each row has: gate id, requirement description, phase, plan, test file path, test count, commit hash, status.
- To re-run any gate locally:
  ```bash
  npx vitest run <test-file-path>
  ```
- To audit a v2.13+ change: walk the gates this doc lists; if any FAIL after the change, the change broke a v2.12 invariant — investigate before merging.
- Total v2.12 ship-gate test count: **275 tests across 14 test files** (verified 2026-05-04 via `npx vitest run --reporter=verbose` aggregation).

## TPLREND-05 byte-identity (PTF gates)

The TPLREND-05 byte-identity invariant: every decoration's React subtree must
be IDENTICAL between the Satori PNG export path (`buildSlideElement` →
`renderToStaticMarkup`) and the React DOM preview path (`<SlidePreview />`).
PTF gates compare the decoration slice (extracted by `data-decoration-id`) and
assert BOTH cross-renderer byte-identity AND a committed baseline snapshot pin.
