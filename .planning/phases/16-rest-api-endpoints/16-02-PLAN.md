     a. Fetch project with user_id filter
     b. Validate bounds
     c. Return the slide at the given index

   - Export `async function renderSlide(project: Project, slideIndex: number, brandKit: BrandKit | null): Promise<ArrayBuffer>`:
     a. Get slide from project.slide_data[slideIndex], throw if not found
     b. Get template via getTemplate(project.template_id ?? 'bold-minimal')
     c. Apply brand kit: mergeWithBrandKit(template, brandKit)
     d. Build element: buildSlideElement(slide, effectiveTemplate)
     e. Load fonts: loadFontBuffersForSlide(slide, effectiveTemplate)
     f. Create ImageResponse with width=1080, height=1920
     g. Return imageResponse.arrayBuffer()
   - Export `async function renderAllSlidesToZip(project: Project, brandKit: BrandKit | null): Promise<Buffer>`:
     a. Create new JSZip()
     b. Loop SEQUENTIALLY through project.slide_data (NOT Promise.all -- avoid memory pressure on serverless)
     c. For each slide: renderSlide(project, i, brandKit), add to zip as `slide-${String(i+1).padStart(2,'0')}.png`
     d. Return `zip.generateAsync({ type: 'nodebuffer' }) as Promise<Buffer>`
   - Export `async function getBrandKitForUser(userId: string): Promise<BrandKit | null>`:
     a. Use createAdminClient() to fetch brand_kits where user_id = userId
     b. Return brand kit or null

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> API | Untrusted slide edit payloads and URL parameters |
| API -> Pexels | External image search via user-provided query strings |
| API -> render | Slide data rendered to PNG -- user content in images |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-06 | Tampering | PATCH slides | mitigate | Zod schema validates all fields; style_overrides bounded (opacity 0-100); background_url must be https:// |
| T-16-07 | Tampering | Slide index | mitigate | parseInt + bounds check against slide_data.length; NOT_FOUND on invalid |
| T-16-08 | Denial of Service | ZIP download | mitigate | maxDuration=60, rate limiting, sequential render to cap memory, max 20 slides enforced by carousel schema |
| T-16-09 | Tampering | Editor service | mitigate | All queries filter by user_id; admin client used with explicit ownership check |
| T-16-10 | Information Disclosure | Render endpoint | mitigate | Only project owner can trigger render -- user_id filter on project fetch |
| T-16-11 | Spoofing | background_url | mitigate | Only https:// URLs accepted; no server-side fetch of arbitrary URLs (URL stored as reference only) |
</threat_model>
