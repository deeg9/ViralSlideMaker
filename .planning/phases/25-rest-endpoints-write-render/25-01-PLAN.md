## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> POST /carousel | Untrusted topic/templateId/options from API consumer |
| client -> POST /projects | Untrusted title/topic from API consumer |
| client -> PATCH /slides | Untrusted slide patch data including URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | S (Spoofing) | All endpoints | mitigate | withApiAuth validates Bearer token via SHA-256 hash lookup |
| T-25-02 | T (Tampering) | PATCH /slides background_url | mitigate | Validate background_url starts with https:// to prevent javascript: or data: injection |
| T-25-03 | I (Info Disclosure) | POST /carousel errors | mitigate | Catch all errors in carousel service, return generic messages via apiError, no stack traces |
| T-25-04 | D (DoS) | POST /carousel | mitigate | Rate limiting via withApiAuth + credit gate prevents abuse; maxDuration=60 limits compute |
| T-25-05 | E (Elevation) | Project access | mitigate | All queries filter by userId from authenticated API key context, preventing cross-user access |
| T-25-06 | T (Tampering) | POST /carousel slideCount | mitigate | Clamp slideCount to 3-20 range server-side regardless of input |
</threat_model>
