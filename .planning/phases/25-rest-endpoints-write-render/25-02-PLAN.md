2. Export `GET = withApiAuth(async (req, ctx) => { ... })`:
   - Extract project `id` from URL segments (index 4)
   - Validate id, return 404 if missing
   - Fetch project with `getProject(ctx.supabase, ctx.userId, id)` -- catch, return 404
   - Get slide_data array, cast slides to `Slide[]`. If empty, return 404
   - Get template: `getTemplate(project.template_id ?? 'bold-minimal')`
   - Fetch brand kit: `ctx.supabase.from('brand_kits').select('*').eq('user_id', ctx.userId).single()`
   - Apply brand kit: `mergeWithBrandKit(template, brandKit ?? null)`
   - Render each slide to PNG using the SAME pattern as `/api/render/route.ts`:
     ```
     import { ImageResponse } from 'next/og'
     import { buildSlideElement } from '@/lib/render/render-slide-satori'
     import { loadFontBuffersForSlide } from '@/lib/render/load-font'
     ```
     For each slide:
     - `const element = buildSlideElement(slide, effectiveTemplate)`
     - `const fonts = await loadFontBuffersForSlide(slide, effectiveTemplate)`
     - `const imgRes = new ImageResponse(element, { width: 1080, height: 1920, fonts })`
     - `const buffer = await imgRes.arrayBuffer()`
   - Render slides sequentially (not in parallel) to avoid memory pressure. Each ImageResponse allocates a canvas.
   - Create ZIP using JSZip (already in package.json):
     ```
     import JSZip from 'jszip'
     const zip = new JSZip()
     // For each rendered buffer:
     zip.file(`slide-${String(i + 1).padStart(2, '0')}.png`, Buffer.from(buffer))
     const zipBuffer = await zip.generateAsync({ type: 'nodebuffer' })
     ```
   - Return raw Response (NOT apiSuccess -- this is binary):
     ```
     const response = new Response(zipBuffer, {
       status: 200,
       headers: {
         'Content-Type': 'application/zip',
         'Content-Disposition': `attachment; filename="${project.title || 'carousel'}.zip"`,
       },
     })
     ```
   - IMPORTANT: Since this returns a raw Response (not NextResponse from apiSuccess), the withApiAuth HOC still adds CORS/rate-limit/credit headers to it. Verify that withApiAuth's header enrichment works on raw Response objects -- it calls `response.headers.set()` which works on any Response.

   - No credits deducted for download (rendering uses already-generated data).
