<task type="auto">
  <name>Task 1: Install dnd-kit and create editor server actions</name>
  <files>
    src/app/(dashboard)/project/[id]/editor-actions.ts
  </files>
  <action>
    1. Install @dnd-kit packages:
       `npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities`

    2. Create `src/app/(dashboard)/project/[id]/editor-actions.ts` with 'use server' directive containing:

    **saveSlideData(projectId: string, slides: Slide[]):**
    - Updates projects.slide_data in Supabase
    - Returns { success: true } or { success: false, error: string }
    - Revalidates the project path

    **searchBackgroundPhotos(query: string):**
    - Calls existing `searchPhotos(query, { orientation: 'portrait', per_page: 12 })`
    - Returns array of `{ id: number, url: string, thumbnail: string, photographer: string }`
    - Maps from Pexels Photo type to simplified shape

    **regenerateSlideText(projectId: string, slideIndex: number, topic: string, currentSlide: Slide):**
    - Uses GoogleGenAI with gemini-2.5-flash
    - Prompt: asks for a fresh alternative hook_text and body_text for a carousel slide about the topic, given the current text
    - Uses responseMimeType: 'application/json' with a schema for { hook_text: string, body_text: string }
    - Returns the new text fields

    **regenerateSlideImageQuery(topic: string, currentSlide: Slide):**
    - Uses GoogleGenAI with gemini-2.5-flash
    - Prompt: generate a new Pexels image search query for a carousel slide about the topic
    - Returns { image_query: string, background_url: string, pexels_photo_id: number | null }
    - After getting new query, calls searchPhotos to get the first result

    **createUploadUrl(projectId: string, fileName: string):**
    - Creates Supabase Storage signed upload URL in 'slide-backgrounds' bucket
    - Path: `${projectId}/${Date.now()}-${fileName}`
    - Returns { signedUrl, path, publicUrl }

    3. Create the Supabase Storage bucket 'slide-backgrounds' if it doesn't exist. Add this to the server action file as a helper or run it via Supabase CLI/dashboard. The bucket should be public (for serving images via public URLs). If Supabase CLI is available, run:
       `npx supabase storage create slide-backgrounds --public`
    Otherwise, create the bucket programmatically on first upload attempt.

    NOTE: Use Gemini 2.5 Flash (@google/genai) for AI operations, NOT Anthropic Claude. Import GoogleGenAI from @google/genai.
  </action>
