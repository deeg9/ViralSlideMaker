<feature>
  <name>Editor State Management with Undo/Redo</name>
  <files>src/lib/types/slide.ts, src/lib/editor/editor-actions.ts, src/lib/editor/editor-reducer.ts, src/lib/editor/use-slide-editor.ts, src/__tests__/editor/reducer.test.ts</files>
  <behavior>
    Slide Type Extension:
    - Add optional `style_overrides?: SlideStyleOverrides` to Slide interface
    - SlideStyleOverrides: { hook_font_size?: number, body_font_size?: number, text_color?: string, text_position?: 'top' | 'center' | 'bottom' }
    - All new fields are optional -- existing data without them still works

    Reducer Actions:
    - ADD_SLIDE { index: number } -> inserts blank slide (empty strings, is_cta: false, null urls) at index
    - REMOVE_SLIDE { index: number } -> removes slide at index, no-op if only 1 slide
    - DUPLICATE_SLIDE { index: number } -> deep clones slide at index, inserts copy at index+1
    - REORDER_SLIDES { from: number, to: number } -> moves slide from `from` to `to` index
    - UPDATE_SLIDE { index: number, updates: Partial<Slide> } -> merges updates into slide at index
    - SET_SLIDES { slides: Slide[] } -> replaces all slides (for AI regeneration results)
    - UNDO -> restores previous state from past, pushes current to future
    - REDO -> restores next state from future, pushes current to past

    History:
    - All actions except UNDO/REDO push current state to past and clear future
    - Past is capped at 50 entries (oldest dropped)
    - UNDO with empty past returns state unchanged
    - REDO with empty future returns state unchanged

    useSlideEditor Hook:
    - Takes initial Slide[] as argument
    - Returns { slides, dispatch, canUndo, canRedo, undo, redo, isDirty }
    - isDirty: true if past has any entries (slides have been modified)
  </behavior>
  <implementation>
    1. Extend Slide type in src/lib/types/slide.ts with optional style_overrides
    2. Create EditorAction union type in src/lib/editor/editor-actions.ts
    3. Create EditorHistory interface and editorReducer in src/lib/editor/editor-reducer.ts
    4. Create useSlideEditor hook in src/lib/editor/use-slide-editor.ts
    5. Follow the past/present/future undo/redo pattern from research
  </implementation>
</feature>
