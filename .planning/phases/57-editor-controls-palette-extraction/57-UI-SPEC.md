## Component Spec — `<PhotoTreatmentControls>`

**Path:** `src/components/editor/photo-treatment-controls.tsx`
**Type:** Client component (`'use client'`)
**Mount point:** `text-editor-panel.tsx` main column, AFTER `<SlideSettings>`, BEFORE conditional `<CustomTextEditor>`. Snapshot test pins this order (EDITOR-04).

### Props

```ts
interface PhotoTreatmentControlsProps {
  slide: Slide
  template: SlideTemplate
  isPending: boolean // from useTransition() — drives spinner
  onTreatmentChange?: (spec: {
    kind: 'bw' | 'duotone-cream' | 'duotone-cobalt' | 'none'
    grain?: 'subtle' | 'medium' | 'heavy' | 'off'
  }) => void
}
```

### Layout (top → bottom inside outer card)

```
┌──────────────────────────────────────────────┐
│  PHOTO TREATMENT                  [pending?] │  ← section title row, h=14px
├──────────────────────────────────────────────┤
│  Black & White                       [SWITCH]│  ← Switch (radix) row, h=24px
├──────────────────────────────────────────────┤
│  DUOTONE                                     │  ← subsection label
│  [ Off ]  [ Cream ]  [ Cobalt ]              │  ← 3-radio row, gap-2, h=32px
├──────────────────────────────────────────────┤
│  GRAIN                                       │  ← subsection label
│  [ Off ]  [ Subtle ]  [ Medium ]  [ Heavy ]  │  ← 4-radio row, gap-2, h=32px
└──────────────────────────────────────────────┘
```

Total height ~196px (matches SlideSettings density).

### Sub-components

#### 1. Section title row

- Uppercase label "PHOTO TREATMENT"
- Right side: `[pending?]` shows a small spinner (`<Icon name="progress_activity">`) + "Treating…" copy in `#3d0000` when `isPending === true`. Hidden otherwise. Reserved space ~80px wide so title doesn't shift.

#### 2. B&W toggle row

- Left: label "Black & White" — `text-[11px] font-semibold text-[#3d0000]`
- Right: `<Switch>` from `@radix-ui/react-switch` (already a project dep)
  - ON state: track `bg-[#3d0000]`, thumb `bg-white`
  - OFF state: track `bg-[#fadbdb]`, thumb `bg-white`
  - Size: 36×20px (smaller than default)
- onChange: emit `onTreatmentChange({ kind: <new>, grain: currentGrain })`

#### 3. Duotone radio row

- Subsection label "DUOTONE" (uppercase tracking)
- 3 radio buttons:
  - Off → `kind: 'none'` if B&W also off; otherwise no-op
  - Cream → `kind: 'duotone-cream'`
  - Cobalt → `kind: 'duotone-cobalt'`
- Mutually exclusive with B&W toggle: selecting any duotone turns B&W OFF visually (single source of truth — user can't have both at once at the spec level since `kind` is one string).
- Active style: `bg-[#3d0000] text-white` + small color swatch dot (cream `#F5EFE6` or cobalt `#0047AB`) prefixed inside the chip
- Inactive style: `bg-white text-[#7d6161] border border-[#dbc1bc]/30 hover:bg-[#fadbdb]`
- Size: `px-3 py-1.5 rounded-lg text-[11px] font-bold uppercase tracking-widest`

#### 4. Grain radio row

- Subsection label "GRAIN" (uppercase tracking)
- 4 radio buttons: Off / Subtle / Medium / Heavy → maps to `grain` arg
  - Off → `grain: 'off'`
  - Subtle → `grain: 'subtle'`
  - Medium → `grain: 'medium'`
  - Heavy → `grain: 'heavy'`
- Active/inactive styling identical to duotone row (consistency)
- Size: `px-2.5 py-1.5 rounded-lg text-[11px] font-bold uppercase tracking-widest` (slightly tighter px so 4 fit at panel width)

### Disabled-state stub (D-12)

When `slide.original_source_url == null && slide.background_url == null` (text-only slide):

```
┌──────────────────────────────────────────────┐
│  PHOTO TREATMENT                             │
│                                              │
│  Add a photo to apply treatments.            │  ← centered, #dbc1bc text
│                                              │
└──────────────────────────────────────────────┘
```

Switch + radios are NOT rendered. Outer card still visible to preserve layout rhythm.

### Active-value mirroring

Resolve current treatment from slide data:

```ts
const activeKind = slide.style_overrides?.treatment_applied?.startsWith('bw') ? 'bw'
  : slide.style_overrides?.treatment_applied?.startsWith('duotone-cream') ? 'duotone-cream'
  : slide.style_overrides?.treatment_applied?.startsWith('duotone-cobalt') ? 'duotone-cobalt'
  : 'none'

const activeGrain = slide.style_overrides?.grain_intensity ?? 'off'
```

Switch ON if `activeKind === 'bw'`. Duotone radio matches `activeKind`. Grain radio matches `activeGrain`.

## Component Spec — IG Grid Chip + Overlay

### Chip

**Mount point:** `slide-canvas.tsx`, INSIDE the existing `mt-4 bg-white px-4 py-2 rounded-full` counter pill row, immediately to the RIGHT of "Slide X / N".

```
┌────────────────────────────────────────────┐
│  Slide 2 / 5    │    🟢 IG GRID            │
└────────────────────────────────────────────┘
                  ↑ vertical divider, 1px #dbc1bc, h=12px
```

- Chip button: `<button>` element
- ON state: `bg-[#3d0000] text-white px-3 py-0.5 rounded-full text-[10px] font-bold uppercase tracking-widest` + small dot indicator
- OFF state: `bg-transparent text-[#7d6161] hover:bg-[#fadbdb] px-3 py-0.5 rounded-full text-[10px] font-bold uppercase tracking-widest border border-[#dbc1bc]/30`
- Toggle: `useState<boolean>(false)` — local to slide-canvas, not lifted

### Overlay

**Mount point:** `slide-canvas.tsx`, INSIDE the SlidePreview's `relative w-full max-w-md` parent — as a sibling to the rendered SlidePreview, absolutely positioned.

```
SlidePreview wrapper (relative, max-w-md, aspect-ratio 9:16)
  ├── SlidePreview (existing)
  └── IGGridOverlay (NEW, absolutely positioned)
        - top: 0
        - left: 0
        - right: 0
        - bottom: 28.125%   ← (1 - 1350/1920) × 100% = 29.6875%
                                rounded to 28.125% to align dashes with grid
        - outline: 2px dashed rgba(255,255,255,0.85)
        - outline-offset: -2px (so the line sits just inside the frame)
        - pointer-events: none
        - z-index: 10
        - mounted only when chipState === ON
```

Visually: a dashed white box covering the top ~70% of the canvas, indicating the IG feed crop (top-aligned). Pointer-events disabled — click-through to underlying SlidePreview is preserved.

**Optional sub-label** (recommended for clarity, score-friendly): a tiny pill OUTSIDE the dashed box at top-right, e.g.:

```
        ┌─────────────────┐
   ┌────│  4:5 IG FEED    │── ↓ dashed border continues
   │    └─────────────────┘
   │                              IGGridOverlay starts here
   │                              ··················
   ·  · · · · · · · · · · · · · ·
```

Pill: `absolute -top-3 right-2 px-2 py-0.5 bg-[#3d0000] text-white text-[9px] font-bold uppercase tracking-widest rounded-full`. Optional — implementer may omit if it adds visual noise.

### CSS-only enforcement (D-04 echo)

- ZERO `filter:` properties on overlay (no `filter: grayscale`, no `filter: blur`)
- ZERO mutations to SlidePreview rendering — overlay is a SIBLING div
- ZERO impact on Satori PNG export (Satori path doesn't render this canvas)

## Interaction States

### PhotoTreatmentControls

| State | Trigger | Visual |
|-------|---------|--------|
| Idle | Initial mount | All controls reflect current slide treatment_applied + grain_intensity |
| User clicks B&W switch | Switch onChange | Switch flips immediately (optimistic). Spinner appears in title row. After server returns, slide preview updates. |
| User clicks duotone radio | Radio onChange | Selected radio gains active style immediately. B&W switch turns OFF visually. Spinner appears. |
| User clicks grain radio | Radio onChange | Selected radio gains active style immediately. NO server treatment call (grain is renderer-only) — instead, optimistic update + saveSlideData persist. Spinner shown only briefly. |
| Server failure | onTreatmentChange Promise rejects | Toast notification ("Treatment failed — try again"). Controls revert to last successful state. |
| Slide has no photo | `original_source_url == null && background_url == null` | Disabled stub renders. Toggle/radios omitted. |
| Pending (3s cache miss) | `isPending === true` | Spinner + "Treating…" in title row. Switch + radios remain interactive (rapid clicks debounced server-side). |
| Pending (cache hit) | Treatment was previously cached | Server returns ~instantly; spinner barely visible. Acceptable — no special UI. |

### IG Grid

| State | Trigger | Visual |
|-------|---------|--------|
| Idle (default OFF) | Initial mount | Chip in OFF style; no overlay |
| User clicks chip | Toggle | Chip flips to ON style; dashed overlay fades in (`transition-opacity duration-150`); session-local |
| User navigates to next slide | Slide change | Chip state PRESERVED across slides (component-local state in slide-canvas) |
| User reloads page | Page reload | Chip resets to OFF (not persisted — D-21) |

## Accessibility

| Rule | Implementation |
|------|----------------|
| Switch is keyboard-operable | `@radix-ui/react-switch` provides keyboard support out of the box (Space to toggle) |
| Radio buttons keyboard-operable | Render as `<button role="radio" aria-checked>` (or shadcn RadioGroup if present) — Tab + Enter to activate |
| Color contrast on active states | `#3d0000` on `#ffffff` = 14.4:1 (AAA); `#7d6161` on `#fff0f0` = 4.7:1 (AA Normal) |
| Disabled-state copy is screen-reader visible | Plain text inside same outer card, no `aria-hidden` |
| IG grid chip has accessible name | `aria-label="Toggle Instagram feed crop preview"` |
| IG grid overlay does not trap focus | `pointer-events: none` + no tabindex |
| Treatment changes are announced | Optional `aria-live="polite"` on the title row spinner so "Treating…" announces to AT |
