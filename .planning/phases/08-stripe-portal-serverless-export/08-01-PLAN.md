    **Step 1: Create `src/lib/render/render-slide-satori.tsx`**

    This file replaces the HTML-string approach with a Satori-compatible React element builder.

    Satori does NOT support HTML strings -- it requires React elements (JSX). Satori does NOT support z-index. Use flexbox layout with absolute positioning via `position: absolute` on a wrapping div.

    Export a function `buildSlideElement(slide: Slide, template: SlideTemplate): React.ReactElement` that returns JSX matching the current HTML layout:

    - Root div: `width: 1080, height: 1920, display: 'flex', position: 'relative', overflow: 'hidden'`
    - If `slide.background_url` exists, use `backgroundImage: url(...)`, `backgroundSize: 'cover'`, `backgroundPosition: 'center'`
    - Otherwise use `backgroundColor: template.backgroundColor`
    - Overlay div: `position: 'absolute', top: 0, left: 0, right: 0, bottom: 0, backgroundColor: template.overlayColor, opacity: template.overlayOpacity`
    - Hook text div: `position: 'absolute'`, positioned using the same SAFE zone constants from render-slide.ts:
      - `SAFE.x = 11` (percentage from left -- convert to pixels: `Math.round(1080 * 0.11) = 119`)
      - Top positions by preset: top={hookY:12,bodyY:30}, center={hookY:30,bodyY:48}, bottom={hookY:48,bodyY:62}
      - Convert percentages to pixels: e.g. hookY=30 -> `Math.round(1920 * 0.30) = 576`
      - Width = `1080 - 119*2 = 842` pixels (symmetric margins)
      - Font size: parse template.hookFontSize (e.g. "64px") -> number, use as-is. For overrides: `overrides.hook_font_size` is already a number.
      - fontWeight: 900, lineHeight: 1.1
      - Apply hookStyle: 'uppercase' -> textTransform: 'uppercase', 'italic' -> fontStyle: 'italic'
    - Body text div: same pattern with body positions and bodyFontSize, fontWeight: 400, lineHeight: 1.5, opacity: 0.9

    Use percentage-to-pixel conversion helper:
    ```typescript
    const W = 1080, H = 1920
    function pxX(pct: number) { return Math.round(W * pct / 100) }
    function pxY(pct: number) { return Math.round(H * pct / 100) }
    ```

    The function returns JSX (not a string). This file must have `.tsx` extension.
