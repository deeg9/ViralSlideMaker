  <instructions>
    Create `src/lib/onboarding/actions.ts` with `'use server'` directive at the top.

    1. `markOnboardingComplete()`:
       - Get current user via `await createClient()` then `supabase.auth.getUser()`.
       - If no user, return `{ success: false, error: 'Not authenticated' }`.
       - `await supabase.from('profiles').update({ onboarding_completed_at: new Date().toISOString() }).eq('id', user.id)`.
       - Check the error field; if present, return `{ success: false, error: error.message }`.
       - `revalidatePath('/dashboard')` so the server-fetched onboarding_completed_at refreshes on next render.
       - Return `{ success: true }`.

    2. `restartOnboarding()`:
       - Same auth check.
       - `update({ onboarding_completed_at: null })`.
       - `revalidatePath('/dashboard')`.
       - `revalidatePath('/settings/profile')`.
       - Return `{ success: true }` on success.

       Do NOT call `redirect()` from this action — Plan 06's settings page button does the redirect after the action resolves.

    3. Import `revalidatePath` from `next/cache`.

    4. Both actions are imported by client components (the provider's `onComplete` prop) — Next.js correctly bridges server actions to client. No HTTP boilerplate needed.
  </instructions>
