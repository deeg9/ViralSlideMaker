    Write `src/components/onboarding/interactive-onboarding-checklist.tsx` as a `'use client'` component.

    1. Imports:
       - `'use client'` first line.
       - `useCallback`, `useEffect`, `useMemo`, `useRef`, `useState` from `react`.
       - `useRouter, usePathname` from `next/navigation`.
       - `AnimatePresence`, `motion` from `'motion/react'`. (NEVER `framer-motion`.)
       - `useOnboarding` from `./onboarding-provider`.
       - Icons (CheckCircle2, Circle, ChevronLeft, ChevronRight, X) from `lucide-react`.

       - `cn` from `@/lib/utils`.

    2. Component skeleton:
       ```typescript
       export function InteractiveOnboardingChecklist() {
         const { needsOnboarding, welcomeSeen, activeStepId, completedStepIds, isComplete,
                 steps, startStep, completeStep, dismissActiveStep, skipTour } = useOnboarding()
         const router = useRouter()
         const pathname = usePathname()

         // Gate: render nothing when checklist should not show
         const checklistVisible = needsOnboarding && welcomeSeen && !isComplete
         if (!checklistVisible) return null

         return (
           <>
             <ChecklistCard ... />
             {activeStepId && <CoachmarkOverlay stepId={activeStepId} ... />}
           </>
         )
       }
       ```

    3. ChecklistCard (inline subcomponent):
       - Fixed positioning: `fixed bottom-6 right-6 z-40 w-[320px]` (z-40 to sit BELOW the coachmark which uses z-50).
       - Header row: title "Get started" + a small X icon button on the right (calls `skipTour()` — dismisses entire tour).
       - Progress bar: a 4px-tall `bg-[#fadbdb]` track with `bg-[#3d0000]` fill at `(completedStepIds.length / steps.length) * 100%` width, with a `motion.div` `animate={{ width: ... }}` transition.
       - Step list: for each step, a button row with:
         - Left icon: `CheckCircle2` (filled) when `completedStepIds.includes(step.id)`, else `Circle` (outline).
         - Title (step.title) + dimmed body line ("Tap to go there" or step.description excerpt).
         - Click handler: `startStep(step.id)` + `if (pathname !== step.route) router.push(step.route)`.
         - Disabled when `completedStepIds.includes(step.id)` OR when `activeStepId === step.id`.
       - Bottom-of-card "Skip tour" small text link calling `skipTour()`.

       Use `motion.div` with `initial={{ y: 16, opacity: 0 }} animate={{ y: 0, opacity: 1 }} exit={{ y: 16, opacity: 0 }}` for the card mount/unmount inside `<AnimatePresence>`.

    4. CoachmarkOverlay (inline subcomponent):
       - Receives `stepId: OnboardingStepId`.
       - Looks up the step def by id.
       - In a `useEffect` (deps `[stepId, pathname]`):
         - `document.querySelector(step.targetSelector)` to find the target.
         - If found, compute the bounding rect with `getBoundingClientRect()`.
         - Set local state `targetRect` or `null`.
         - Re-run on window resize (`addEventListener('resize', ...)`) and on a 200ms-debounced ResizeObserver against `document.body` (target may move).
       - If `targetRect` is non-null:
         - Render a `motion.div` "spotlight ring" at the target's coords with `position: fixed; top/left/width/height` set from the rect, with a glow + 2px ring (`outline: 2px solid #3d0000; outline-offset: 4px; border-radius: 12px; pointer-events: none; z-50`).
         - Render a "tooltip" panel positioned NEAR the target (top → bottom → right → left preference; clamp inside viewport). Tooltip contains: step.title, step.description, a row of buttons: `Prev` (calls `completeStep(prev.id)` + `startStep(prev.id)` or no-op on first step), `Skip` (calls `skipTour()`), `Next` (calls `completeStep(stepId)` — provider auto-advances activeStepId via `startStep(next.id)` or auto-finishes via `finishTour` if last).
       - If `targetRect` is null (target not in DOM — D-09 fallback):
         - Render a centered modal-style panel (`position: fixed; inset-0; flex items-center justify-center`).
         - Body: step.title + step.description + a `Take me there` button that calls `router.push(step.route)`. Show same Prev / Skip / Next controls.

       Important behaviors:
       - The spotlight ring (the absolute `motion.div`) MUST have `pointer-events: none` so the user can still interact with the underlying element (per spec).
       - The tooltip itself is pointer-events:auto.
       - Backdrop dim: render a fixed inset-0 div with `bg-black/40 pointer-events-none` BEHIND the spotlight (z-49). Pointer-events-none lets clicks pass through to the underlying app. This is acknowledgement-based — clicking the spotlight target itself is encouraged but not required to advance.

       Next/Prev wiring detail:
       - After computing `completeStep(stepId)`, look up the next non-completed step in `steps` order:
         ```typescript
         const nextStep = steps.find(s => !completedStepIds.includes(s.id) && s.id !== stepId)
         if (nextStep) startStep(nextStep.id)
         // else provider's completeStep already scheduled finishTour
         ```
       - Auto-navigate (`router.push(nextStep.route)`) when the next step's route differs from the current pathname.

       Motion-import discipline: every `motion.<x>` and `AnimatePresence` reference comes from `'motion/react'`. If you transcribe a supplied design that imports from `framer-motion`, REWRITE the import line. There must be ZERO `framer-motion` substrings in this file.

    5. Cleanup: when the component unmounts (because `isComplete` flipped true or `welcomeSeen` flipped false during reset), remove the resize / ResizeObserver listeners in the useEffect return.
