2. Match by role: hook click → `text_boxes.find((tb) => tb.role === 'hook')`; body click → role='body'

### T-02 — Selection ring on active text box

**File:** `src/components/slides/slide-preview.tsx`

For each text-box wrapper element (hook, body, custom_texts), conditionally apply ring className when:
- `editable === true` (NEVER in Satori export path)
- `selectedTextBoxId !== null`
- The element's matched TextBox.id === selectedTextBoxId

Ring className: `outline outline-2 outline-dashed outline-[#3d0000] outline-offset-2 rounded-sm`. Pure CSS, no JS animation.

Important: `outline` (not `border`) — outline doesn't affect layout, doesn't conflict with existing borders, and is ignored by Satori (so it never leaks into PNG exports).

Add a small unit/regression test:
```tsx
test('selection ring renders on active hook text box in editable mode', () => {
  render(<SlidePreview slide={fixture} editable={true} selectedTextBoxId={hookId} ... />)
  const hookEl = screen.getByTestId('hook-text-wrapper')
  expect(hookEl.className).toContain('outline-dashed')
})

test('selection ring does NOT render in non-editable (export) mode', () => {
  render(<SlidePreview slide={fixture} editable={false} selectedTextBoxId={hookId} ... />)
  const hookEl = screen.getByTestId('hook-text-wrapper')
  expect(hookEl.className).not.toContain('outline-dashed')
})
```

**Acceptance:** Active text box shows dashed `#3d0000` outline in editable mode; never in export mode.

Commit: `feat(52): selection ring on active text box (editable mode only)`

### T-03 — Keyboard shortcuts

**File:** `src/components/editor/slide-editor.tsx`

Add a `useEffect` keyboard listener:

```tsx
useEffect(() => {
  function handler(e: KeyboardEvent) {
    // Skip if focused in editable input
    const tag = (document.activeElement?.tagName ?? '').toLowerCase()
    const isEditing = tag === 'input' || tag === 'textarea' || (document.activeElement as HTMLElement)?.isContentEditable
    if (isEditing) return

    const cmd = e.metaKey || e.ctrlKey
    const textBoxes = currentSlide?.text_boxes ?? []

    if (cmd && (e.key === '1' || e.key === '2' || e.key === '3')) {
      const idx = parseInt(e.key, 10) - 1
      const target = textBoxes[idx]
      if (target) {
        e.preventDefault()
        setSelectedTextBoxId(target.id)
      }
    } else if (cmd && (e.key === 'd' || e.key === 'D')) {
      e.preventDefault()
      const newId = crypto.randomUUID()
      dispatch({ type: 'ADD_TEXT_BOX', slideIndex: selectedIndex, role: 'custom', defaults: { id: newId } })
      setSelectedTextBoxId(newId)
    } else if ((e.key === 'Delete' || e.key === 'Backspace') && selectedTextBoxId) {
      const target = textBoxes.find((tb) => tb.id === selectedTextBoxId)
      if (target?.role === 'custom') {
        e.preventDefault()
        removeTextBox(selectedIndex, selectedTextBoxId)
      }
      // Don't allow deleting hook/body — they're structural
    }
  }
  window.addEventListener('keydown', handler)
  return () => window.removeEventListener('keydown', handler)
}, [currentSlide, selectedTextBoxId, selectedIndex, setSelectedTextBoxId, removeTextBox, dispatch])
```

Add tests:
```tsx
describe('keyboard shortcuts', () => {
  test('Cmd+1 selects first text box')
  test('Cmd+2 selects second text box')
  test('Cmd+D adds new custom text box and auto-selects it')
  test('Delete removes custom text box (preserves hook/body)')
  test('shortcuts do nothing when typing in textarea')
})
```

**Acceptance:** Shortcuts work as specified. Ignored when typing.

Commit: `feat(52): keyboard shortcuts (Cmd+1/2/3, Cmd+D, Delete)`
