  <action>
    **src/lib/imagen/generate-image.ts:**
    Create `generateImagenBackground(userId, prompt, projectId, slideIndex)` that:
    1. Calls `deductCredit(userId, 'imagen_generation', 'AI background: ' + prompt.slice(0,50), projectId)` -- return `{ error: 'Insufficient credits' }` if false
    2. Truncate prompt to 350 words max as safety net (Imagen has 480-token limit)
    3. Call `ai.models.generateImages({ model: 'imagen-4.0-fast-generate-001', prompt, config: { numberOfImages: 1, aspectRatio: '9:16', includeRaiReason: true } })`
    4. Check `response.generatedImages?.[0]?.image?.imageBytes` -- if absent, call `refundCredit()` and return `{ error: raiFilteredReason ?? 'Content filtered by safety policy', refunded: true }`
    5. `Buffer.from(imageBytes, 'base64')`, upload to `slide-backgrounds` bucket at path `${userId}/${projectId}/ai-${slideIndex}-${Date.now()}.png`
    6. Get public URL, return `{ url: publicUrl }`
    7. Wrap steps 2-6 in try/catch; on error, call `refundCredit()` and return `{ error: 'Image generation failed. Credit refunded.', refunded: true }`

    `refundCredit(userId, projectId)` helper: uses `createAdminClient()` to insert into `credit_transactions` with `{ user_id: userId, type: 'refund', amount: 1, description: 'Imagen generation failed or filtered', reference_id: projectId }`.

    Export type: `type ImagenResult = { url: string } | { error: string; refunded?: boolean }`

    **src/lib/imagen/generate-prompt.ts:**
    Create `generateImagePrompt(topic, hookText, bodyText, isCta)` that:
    1. Calls `ai.models.generateContent` with model `gemini-2.5-flash`
    2. Prompt instructs: "Generate a concise image prompt for a TikTok carousel slide background. Topic: {topic}, Hook: {hookText}, Body: {bodyText}. {if isCta: 'This is the closing CTA slide.'} Image should be a mood/aesthetic background. Do NOT include text. Focus on atmosphere, colors, visual mood. Keep under 100 words."
    3. Uses structured JSON output: `{ prompt: string }`
    4. Parse response, return the prompt string
    5. On parse error, return a sensible fallback: `"Professional aesthetic background for ${topic}"`

    Both files instantiate their own `const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY! })` (same pattern as editor-actions.ts).

    Add `export const maxDuration = 60` in any file that will be used as a server action entry point (this will be in the actions file, not the lib -- but the lib should be efficient).
