## Interaction Contracts

### AI Generate Tab (IMAGEN-01, IMAGEN-02, IMAGEN-04)

**Entry point:** Third tab in image-picker-panel labeled "AI Generate"

**States:**

1. **Loading prompt** -- User clicks "AI Generate" tab. Auto-prompt generation fires immediately. Show skeleton pulse in textarea (1-2 seconds). Textarea disabled during generation.
2. **Prompt ready** -- Textarea populated with auto-generated prompt. Editable. Below textarea: credit cost badge ("1 credit") and "Generate Image" button. Button is `bg-[#3d0000] text-white` (primary).
3. **Generating image** -- Button disabled, shows spinner icon (Material Symbols `progress_activity`, animate-spin). Textarea disabled. Text below: "Generating image... this may take up to 15 seconds."
4. **Success** -- Generated image appears as a preview thumbnail (same aspect-ratio grid cell style as Pexels results). Auto-applied to slide background. Prompt textarea remains for re-generation.
5. **Safety filtered (refunded)** -- Show inline warning: amber/muted background (`bg-[#fff0f0]`), icon `warning`, text: "Image was blocked by content safety filter. Your credit has been refunded. Try a different description." Prompt textarea remains editable for retry.
6. **Insufficient credits** -- Show inline message with link: "Not enough credits. [Buy more credits](/settings/subscription)" in muted-foreground text.
7. **API error (refunded)** -- Show inline error: "Generation failed. Your credit has been refunded. Please try again."

**Double-click prevention:** Button disables immediately on click via `useTransition` pending state. Re-enables only after server action completes.

### Free User Gate (IMAGEN-03)

**Condition:** `getUserTier()` returns `'free'`

**Behavior:** When free user clicks "AI Generate" tab, show `<UpgradePrompt context="feature_gate" />` instead of the generate form. No textarea, no generate button. The existing UpgradePrompt component renders: title "Premium feature", message "This feature is available on Plus and Pro plans.", button "View Plans" linking to `/settings/subscription`.

### Caption Panel (CAPTION-01, CAPTION-02)

**Entry point:** "Generate Captions" button in the editor toolbar / download controls area. Icon: `auto_awesome`. Button style: secondary (`bg-[#fff0f0] text-[#3d0000]`).

**Layout:** Panel renders below the slide editor (not a modal). Three platform tabs: TikTok, Instagram, LinkedIn. Each tab shows:
- Platform icon (Material Symbols: `tag` for TikTok, `photo_camera` for Instagram, `work` for LinkedIn)
- Generated caption text in a read-only textarea or pre-formatted block
- "Copy" button with icon `content_copy`. On click: copies to clipboard, icon changes to `check` for 2 seconds, reverts.

**States:**

1. **Initial** -- Panel not visible. "Generate Captions" button in toolbar.
2. **Generating** -- Button shows spinner. Panel appears with skeleton pulse lines (3 lines per platform tab).
3. **Ready** -- All three platform captions populated. TikTok tab active by default. User can switch tabs. Each tab has copy button.
4. **Error** -- Inline error in panel: "Caption generation failed. Please try again." with retry button.
5. **Regenerate** -- "Regenerate" button (icon `refresh`) at top of panel to get new captions. Same loading state as initial generation.

**No credits consumed** for caption generation. No credit badge shown. Available to all tiers (free and paid).

## Loading & Transition Patterns

| Action | Duration | Pattern |
|--------|----------|---------|
| Auto-prompt generation (Gemini) | 1-3s | Skeleton pulse in textarea, textarea disabled |
| Imagen image generation | 3-15s | Button spinner + disabled, progress text below button |
| Caption generation (Gemini) | 2-5s | Skeleton pulse lines (3 lines) in each tab |
| Copy to clipboard | Instant | Icon swap: `content_copy` to `check`, revert after 2000ms |
| Tab switching | Instant | No animation, immediate content swap (matches existing tab pattern) |
