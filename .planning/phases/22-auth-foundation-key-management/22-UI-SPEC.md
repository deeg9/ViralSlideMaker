### Component: Create Key Dialog

Uses Base UI `Dialog` component following `create-project-dialog.tsx` pattern exactly.

**Backdrop:** `fixed inset-0 bg-black/40 z-40`

**Popup:**

**State 1 — Name input (pre-creation):**
- Title: "Create API Key"
- Description: "Give your key a name to identify it later."
- Input field: name input following existing pattern (`h-12 rounded-xl border border-[#dbc1bc]/30 bg-[#fff0f0] px-4 text-sm`)
- Label: "KEY NAME" (uppercase label pattern)
- Placeholder: "e.g., Production App"
- Footer: Cancel (outline) + "Create Key" (primary) buttons

**State 2 — Key reveal (post-creation):**
- Title: "API Key Created"
- Warning banner: `bg-[#fff0f0] border border-[#dbc1bc]/30 rounded-xl p-4` with `warning` icon

- Quick-start snippets: tabbed interface below the key display

**Quick-start tabs:**
- Tab bar: 3 tabs — "curl", "JavaScript", "Python"
- Tab styling (active): `bg-[#fadbdb] text-[#3d0000] font-bold px-3 py-2 rounded-lg text-sm`

**Footer (State 2):** Single "Done" button (primary style), closes dialog.

## Interaction States

### Key Creation Flow
1. User clicks "Create API Key" button
2. Dialog opens in State 1 (name input)
3. User types name, clicks "Create Key"
4. Loading state: button shows spinner, input disabled
5. Dialog transitions to State 2 (key reveal with snippets)
6. User copies key, browses snippets, clicks "Done"
7. Dialog closes, table refreshes with new key row

### Key Revocation Flow
1. User clicks "Revoke" on a key row
2. Confirmation dialog opens with key name
3. User clicks "Revoke Key" (destructive)
4. Loading state: button shows spinner
5. Dialog closes, key row removed from table with no animation

### Empty State
When user has no API keys:
- Displayed inside the white card wrapper
- Centered content with 48px vertical padding
- Icon: `key` at 48px, color `text-[#dbc1bc]`
- Heading: "No API keys yet"
- Body: "Create an API key to start using the ViralSlideMaker API programmatically."
- CTA: "Create API Key" primary button (same styling as header button)

### Error States
- Key creation failure: inline error text below the name input in `text-sm text-[#ba1a1a]`
  - Copy: "Failed to create API key. Please try again."
- Key revocation failure: toast/inline error
  - Copy: "Failed to revoke key. Please try again."
- Max keys reached: "Create API Key" button disabled, tooltip or muted text: "Maximum of 10 API keys reached. Revoke an existing key to create a new one."

### Loading States
- Initial page load: table skeleton — 3 rows of `h-4 bg-[#fff0f0] rounded animate-pulse` bars
- Button loading: text replaced with a 16px spinner, button width preserved

## Quick-Start Snippet Templates

### curl
```
curl -X GET https://viralslidemaker.com/api/v1/templates \
  -H "Authorization: Bearer {KEY}"
```

### JavaScript
```
const res = await fetch('https://viralslidemaker.com/api/v1/templates', {
  headers: { 'Authorization': 'Bearer {KEY}' }
});
const data = await res.json();
```

### Python
```
import requests

res = requests.get(
    'https://viralslidemaker.com/api/v1/templates',
    headers={'Authorization': 'Bearer {KEY}'}
)
data = res.json()
```

## Accessibility Requirements

- Dialog traps focus when open (handled by Base UI Dialog)
- Escape key closes dialogs (handled by Base UI Dialog)
- Copy button announces "Copied to clipboard" via `aria-live="polite"` region
- Revoke button has `aria-label="Revoke API key {key_name}"` for screen readers
- Table uses semantic `<table>`, `<thead>`, `<tbody>`, `<th scope="col">` markup
- All inputs have associated `<label>` elements (not just visual labels)
- Focus visible ring: `focus-visible:ring-2 focus-visible:ring-[#3d0000] focus-visible:ring-offset-2`
