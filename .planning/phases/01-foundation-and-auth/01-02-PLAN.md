       - `deleteProject(projectId: string)`: Delete from `projects` where id matches. Revalidate `/dashboard`.
       - `updateProject(projectId: string, data: { title?: string; description?: string })`: Update project fields. Revalidate `/dashboard`.
       - Use the server Supabase client from `@/lib/supabase/server`.
       - Follow the code examples from RESEARCH.md.
