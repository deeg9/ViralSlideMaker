    - Test: downloadSlidesAsZip creates a ZIP with correct number of files named slide-01.png, slide-02.png, etc.

    - Test: SlidePreview applies template textColor and fontFamily as inline styles

  <action>
    1. Create `src/app/api/render/route.ts` -- GET endpoint for server-side slide rendering:
       - Query params: `projectId` (required), `slide` (required, 0-indexed), `download` (optional, triggers attachment header)
       - Fetch project from Supabase (use `createClient` from server), verify it exists
       - Get the slide at the requested index from `slide_data`
       - Get template via `getTemplate(project.template_id)`
       - Build HTML with `buildSlideHtml(slide, template)`
       - Render with `nodeHtmlToImage({ html, type: 'png', puppeteerArgs: { args: ['--no-sandbox', '--disable-setuid-sandbox'] } })`
       - Return PNG buffer with `Content-Type: image/png`
       - If `download` param present, add `Content-Disposition: attachment; filename="slide-{N}.png"`
       - Return 400 for missing params, 404 for missing project/slide

    2. Create `src/lib/download/zip-slides.ts` matching RESEARCH.md:
       - `downloadSlidesAsZip(projectId: string, slideCount: number, projectTitle: string)`
       - Fetch each slide from `/api/render?projectId={id}&slide={i}` in parallel
       - Create ZIP with `jszip`, files named `slide-01.png`, `slide-02.png`, etc.
       - Trigger download with `file-saver`'s `saveAs`

    3. Create `src/components/slides/template-picker.tsx` -- client component:
       - Import `templates` from template registry
       - Display grid of template cards (name + colored preview swatch)
       - Accept `selectedId` and `onSelect(id)` props
       - Highlight selected template with ring/border
       - 2-3 columns on mobile, 5 on desktop

    4. Create `src/components/slides/generation-form.tsx` -- client component:
       - Props: `projectId: string`, `currentTopic?: string`, `currentTemplateId?: string`, `hasSlides: boolean`
       - Text input for topic (textarea, placeholder: "Enter your carousel topic...")
       - Embedded TemplatePicker for template selection (default: bold-minimal)
       - "Generate Carousel" button calling `generateCarousel` server action
       - Loading state: disable button, show spinner, text "Generating slides..."
       - If `hasSlides` is true, show "Regenerate" instead of "Generate"
       - Use `useTransition` for the server action call

    5. Create `src/components/slides/slide-preview.tsx` -- client component:
       - Props: `slide: Slide`, `template: SlideTemplate`, `index: number`
       - Renders a scaled-down CSS preview (not an image) matching the server HTML template
       - Uses inline styles from template: fontFamily, textColor, backgroundColor, overlayColor/opacity
       - Background image via CSS `backgroundImage` if `background_url` exists
       - Aspect ratio 9:16 using `aspect-[9/16]` Tailwind class
       - Shows slide number badge in corner
       - This IS the real-time preview for UIUX-03

    6. Create `src/components/slides/slide-grid.tsx` -- client component:
       - Props: `slides: Slide[]`, `templateId: string`
       - Gets template via `getTemplate(templateId)`
       - Renders grid of SlidePreview components
       - Grid: 2 cols on mobile, 3 on md, 4 on lg
       - Empty state if no slides

    7. Create `src/components/slides/download-controls.tsx` -- client component:
       - Props: `projectId: string`, `slideCount: number`, `projectTitle: string`
       - "Download All (ZIP)" button calling `downloadSlidesAsZip`
       - Individual slide download links: `<a href="/api/render?projectId={id}&slide={i}&download=1">` for each slide
       - Loading state on ZIP download button
       - Disabled if slideCount is 0

    8. Write tests FIRST. Mock `node-html-to-image` in render tests. Mock `fetch` for ZIP tests. Use @testing-library/react for component tests.
