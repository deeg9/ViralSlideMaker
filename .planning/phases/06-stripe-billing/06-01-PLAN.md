  <action>
1. Install dependencies: `npm install stripe @stripe/stripe-js`

2. Create `src/lib/stripe/client.ts`:
   - Export `getStripeServer()` function that returns a singleton `Stripe` instance
   - Initialize with `process.env.STRIPE_SECRET_KEY!`
   - Pin API version to `'2025-12-18.acacia'` with `typescript: true`
   - Use module-level `let stripeInstance: Stripe | null = null` for singleton pattern

3. Create `src/lib/stripe/config.ts`:
   - Export `STRIPE_PRICES` object with keys: `plus_monthly`, `pro_monthly`, `credit_pack_10` -- each reading from env vars `STRIPE_PRICE_PLUS_MONTHLY`, `STRIPE_PRICE_PRO_MONTHLY`, `STRIPE_PRICE_CREDIT_PACK_10`
   - Export `tierFromPriceId(priceId: string): SubscriptionTier | null` -- maps price ID to 'plus' or 'pro', returns null for unknown
   - Export `CREDIT_PACK_AMOUNTS: Record<string, number>` mapping credit pack price IDs to credit amounts. Key = `STRIPE_PRICES.credit_pack_10`, value = `10`

4. Create `src/lib/stripe/sync-subscription.ts`:
   - Export `async function handleStripeEvent(event: Stripe.Event, admin: SupabaseClient): Promise<void>`
   - Switch on `event.type` dispatching to handler functions:

   a) `handleCheckoutCompleted(session: Stripe.Checkout.Session, admin)`:
      - If `session.mode === 'subscription'`:
        - Extract `userId` from `session.metadata?.supabase_user_id`
        - Get subscription details: `const sub = await stripe.subscriptions.retrieve(session.subscription as string)`
        - Resolve tier via `tierFromPriceId(sub.items.data[0].price.id)`
        - Upsert subscriptions row: set `stripe_customer_id = session.customer`, `stripe_subscription_id = session.subscription`, `tier`, `status = 'active'`, `current_period_start = new Date(sub.current_period_start * 1000).toISOString()`, `current_period_end = new Date(sub.current_period_end * 1000).toISOString()`
        - Use `.update().eq('user_id', userId)` (row already exists from ensureSubscription)
      - If `session.mode === 'payment'`:
        - Extract `userId` from `session.metadata?.supabase_user_id`
        - Look up credit amount: `CREDIT_PACK_AMOUNTS[lineItem priceId]` -- retrieve line items via `stripe.checkout.sessions.listLineItems(session.id)` and use first item's `price.id`
        - Insert credit_transactions row: `{ user_id: userId, type: 'credit_pack_purchase', amount: creditAmount, description: 'Credit pack purchase', reference_id: session.id }`

   b) `handleSubscriptionUpdated(subscription: Stripe.Subscription, admin)`:
      - Find user via admin query: `subscriptions.select('user_id').eq('stripe_subscription_id', subscription.id).single()`
      - Resolve new tier from `subscription.items.data[0].price.id`
      - Update subscriptions row: `tier`, `status = subscription.status`, `current_period_start`, `current_period_end`, `cancel_at_period_end = subscription.cancel_at_period_end`

   c) `handleSubscriptionDeleted(subscription: Stripe.Subscription, admin)`:
      - Find user via admin query on `stripe_subscription_id`
      - Update subscriptions: `tier = 'free'`, `status = 'canceled'`, `stripe_subscription_id = null`

   d) `handleInvoicePaid(invoice: Stripe.Invoice, admin)`:
      - Only process if `invoice.subscription` is not null (skip one-time payments)
      - Find user via admin query: `subscriptions.select('user_id, tier').eq('stripe_subscription_id', invoice.subscription).single()`
      - Grant monthly credits: insert credit_transactions row with `type: 'subscription_grant'`, `amount: TIER_CREDITS[tier]`, `description: 'Monthly credit grant ({Tier} tier)'`, `reference_id: invoice.id`

   e) `handlePaymentFailed(invoice: Stripe.Invoice, admin)`:
      - Find user via admin query on `stripe_subscription_id = invoice.subscription`
      - Update subscriptions: `status = 'past_due'`

5. Create `src/app/api/webhooks/stripe/route.ts`:
   - Export `async function POST(request: Request)`
   - Read raw body with `await request.text()` (NEVER `.json()`)
   - Get `stripe-signature` header
   - Verify with `stripe.webhooks.constructEvent(body, signature, process.env.STRIPE_WEBHOOK_SECRET!)`
   - On verification failure: return `NextResponse.json({ error: 'Invalid signature' }, { status: 400 })`
   - Idempotency: query `stripe_events` for `event.id`. If exists, return `{ received: true }` immediately
   - Insert event into `stripe_events` table BEFORE processing: `{ event_id: event.id, event_type: event.type }`
   - Call `handleStripeEvent(event, admin)`
   - Wrap in try/catch: on error, log it but still return 200 (prevent Stripe retries on app bugs)
   - Return `NextResponse.json({ received: true })`

6. Update `.env.local.example`: append these lines:

```
STRIPE_PRICE_CREDIT_PACK_10=price_your-credit-pack-10-price-id
```
