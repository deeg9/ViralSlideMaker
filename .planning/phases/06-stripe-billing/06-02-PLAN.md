1. Create `src/app/(dashboard)/settings/subscription/actions.ts`:
   - Add `'use server'` directive at top
   - Import: `redirect` from `next/navigation`, `createClient` from `@/lib/supabase/server`, `getStripeServer` from `@/lib/stripe/client`, `createAdminClient` from `@/lib/supabase/admin`, `STRIPE_PRICES` from `@/lib/stripe/config`

   a) `export async function createCheckoutSession(priceId: string)`:
      - Get authenticated user via `createClient()` then `supabase.auth.getUser()`
      - If no user, throw `new Error('Not authenticated')`
      - Look up existing `stripe_customer_id` from subscriptions table using admin client: `admin.from('subscriptions').select('stripe_customer_id').eq('user_id', user.id).single()`
      - If no `stripe_customer_id`, create Stripe customer: `stripe.customers.create({ email: user.email, metadata: { supabase_user_id: user.id } })` and update subscriptions row with the new customer ID
      - Create checkout session: `stripe.checkout.sessions.create({ customer: customerId, mode: 'subscription', line_items: [{ price: priceId, quantity: 1 }], success_url: \`\${process.env.NEXT_PUBLIC_APP_URL}/settings/subscription?success=true\`, cancel_url: \`\${process.env.NEXT_PUBLIC_APP_URL}/settings/subscription?canceled=true\`, metadata: { supabase_user_id: user.id } })`
      - Call `redirect(session.url!)`

   b) `export async function createPortalSession()`:
      - Get authenticated user
      - Look up `stripe_customer_id` from subscriptions table via admin client
      - If no customer ID, throw `new Error('No active subscription found')`
      - Create portal session: `stripe.billingPortal.sessions.create({ customer: sub.stripe_customer_id, return_url: \`\${process.env.NEXT_PUBLIC_APP_URL}/settings/subscription\` })`
      - Call `redirect(session.url)`

   c) `export async function createCreditPackCheckout()`:
      - Get authenticated user
      - Look up or create Stripe customer (same pattern as createCheckoutSession)
      - Create checkout session with `mode: 'payment'`: `stripe.checkout.sessions.create({ customer: customerId, mode: 'payment', line_items: [{ price: STRIPE_PRICES.credit_pack_10, quantity: 1 }], success_url: \`\${process.env.NEXT_PUBLIC_APP_URL}/settings/subscription?credits=true\`, cancel_url: \`\${process.env.NEXT_PUBLIC_APP_URL}/settings/subscription\`, metadata: { supabase_user_id: user.id } })`
      - Call `redirect(session.url!)`
