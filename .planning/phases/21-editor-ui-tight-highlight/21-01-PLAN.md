2. **Outline sub-section** (per D: OUT-01, OUT-02, OUT-03):
   - Toggle button with label or icon for "Outline". Same toggle style.
   - When enabled, show:
     - **Color**: Same 4 swatches + custom picker. Outline colors are solid (no alpha suffix needed).
     - **Thickness**: Range slider `min={1} max={8} step={1}` with value label showing current px. Use exact slider pattern: `className="w-full h-1 bg-[#fadbdb] rounded-lg appearance-none cursor-pointer accent-[#3d0000]"`.
   - Default: `{ enabled: true, color: '#000000', width: 2 }` per CONTEXT.md.
   - Toggle off preserves color/width.

3. **Highlight sub-section** (per D: HL-01, HL-02, HL-03, HL-04):
   - Toggle button for "Highlight". Same toggle style.
   - When enabled, show:
     - **Color**: Same 4 swatches + custom picker. Highlight colors need alpha, so append `'88'` to swatch hex on click (e.g. '#3d000088'). Custom picker sends raw hex + '88'.
     - **Style**: 2-button group [Tight] [Full] matching alignment button style. Maps to `'tight' | 'full'`.
     - **Padding**: Range slider `min={4} max={24} step={2}` with value label showing current px.
   - Default: `{ enabled: true, color: '#00000088', style: 'tight', padding: 8 }` per CONTEXT.md.
