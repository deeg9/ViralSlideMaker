  <action>
Create a standalone TypeScript script at `scripts/spike-satori-effects.ts` that directly invokes `ImageResponse` from `next/og` to render three test slides and write the resulting PNGs to `scripts/spike-output/`.

The script must test three CSS properties on text elements:

1. **textShadow test:** Render a slide with a white text element on dark background. Apply `textShadow: '4px 4px 8px #000000'` as an inline style on the text div. Save as `spike-shadow.png`.

2. **WebkitTextStroke test:** Render a slide with white text on dark background. Apply `WebkitTextStrokeWidth: '3px'` and `WebkitTextStrokeColor: '#FF0000'` as inline styles on the text div. Save as `spike-outline.png`.

3. **Combined test:** Render a slide with both `textShadow: '2px 2px 4px #00000080'` AND `WebkitTextStrokeWidth: '2px'`, `WebkitTextStrokeColor: '#FFFFFF'` on the same text element. Save as `spike-combined.png`.

IMPORTANT: Use 8-digit hex colors (e.g., `#00000080`) instead of `rgba()` to avoid Satori Issue #441 parse bug.

The script should:
- Import `ImageResponse` from `next/og`
- Create minimal JSX elements (1080x1920 canvas, dark background div, text div with effect styles)
- Convert ImageResponse to ArrayBuffer, write to disk as PNG
- Log success/failure for each test to stdout
- Exit with code 0 if all three PNGs are produced (non-zero bytes), exit 1 if any fail

Use `tsx` to run (already in devDependencies). Run with: `npx tsx scripts/spike-satori-effects.ts`

After the script runs, verify the output PNGs exist and are non-trivial (> 5KB each, indicating actual rendered content not blank images).

Also add `scripts/spike-output/` to `.gitignore` if not already covered by a glob pattern.
