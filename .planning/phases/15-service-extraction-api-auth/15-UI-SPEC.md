## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, table cell padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, settings content gaps |
| xl | 32px | Layout gaps between settings sidebar and content |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 500 (medium) | 1.4 |
| Heading | 20px | 700 (bold) | 1.2 |
| Display | 28px | 700 (bold) | 1.2 |

Note: Settings pages use Heading (20px) for section titles. Display (28px) is not used in this phase. Label (14px medium) is used for form labels, table headers, and key metadata.

## Layout Specification

### Settings Nav Update

Add new entry to `settingsNav` array in `src/app/(dashboard)/settings/layout.tsx`:

```
{ href: '/settings/api-keys', icon: 'key', label: 'API Keys' }
```

Position: after "Brand Kit" (last item in nav).

### API Keys Page Layout

```
+--------------------------------------------------+
| [Icon: key] API Keys              [Create API Key]|
|                                                    |
| Rate limits: Free 10/min, Plus 30/min, Pro 60/min |
+--------------------------------------------------+
| Name       | Key              | Created  | Last   |  |
|------------|------------------|----------|--------|--|
| Production | vsl_****...a7x2  | Apr 3    | 2h ago | [Revoke] |
| Dev        | vsl_****...k9m1  | Mar 28   | Never  | [Revoke] |
+--------------------------------------------------+
```

- Page heading uses same pattern as other settings pages (20px bold, `text-[#3d0000]`)
- "Create API Key" button: primary variant, right-aligned in heading row
- Table inside a Card component with no extra padding (table fills card)
- Rate limit info: muted-foreground text, 14px, below heading
- Revoke button: `variant="ghost"` with destructive text color, no icon
- Masked key format: `vsl_****...{last 4 chars}` in monospace font (`font-mono`)
- Created date: relative format ("Apr 3") or relative ("2h ago") for last used
- Revoked keys: entire row at 50% opacity, revoke button replaced with "Revoked" badge

### Empty State Layout

```
+--------------------------------------------------+
| [Icon: key] API Keys                              |
+--------------------------------------------------+
|                                                    |
|            [Icon: vpn_key, size xl]               |
|            No API keys yet                         |
|            Create an API key to access the         |
|            Viral Slide Maker API...                |

```

- Centered vertically and horizontally within content area
- Icon: `vpn_key` at xl size, muted-foreground color

- Body: 14px regular, muted-foreground, max-width 320px, text-center
- CTA button: primary variant

### Create Key Dialog

```
+------------------------------------+
| Create API Key                 [X] |
|------------------------------------|
| Give this key a name               |
| [My API key________________]      |
|                                    |
|              [Cancel] [Create Key] |
+------------------------------------+
```

- Standard shadcn Dialog, max-width 420px
- Label input: required, auto-focused on open
- Create Key button: primary variant, disabled while label is empty
- Cancel button: ghost variant

### Key Created State (replaces dialog content)

```
+------------------------------------+
| Your API key                       |
|------------------------------------|
| [!] Copy this key now. You won't   |
|     be able to see it again.       |
|                                    |
| +--------------------------------+ |
| | vsl_a8k2m9x...full key    [Copy]| |
| +--------------------------------+ |
|                                    |
|                           [Done]   |
+------------------------------------+
```

- Warning: destructive color text, 14px, with `warning` Material Symbol icon
- Key display: monospace font, full key text in a bordered box with copy button
- Copy button: icon-only (`content_copy` icon), shows "Copied!" tooltip on click for 2 seconds
- Done button: primary variant, closes dialog
- Dialog is NOT dismissible by clicking outside or pressing Escape while key is displayed (user must click Done)

### Revoke Key Dialog

- Standard shadcn AlertDialog
- Title: "Revoke API key?"
- Body: destructive context copy with key label interpolated
- Cancel: outline variant
- Confirm: destructive variant ("Revoke Key")

## Interaction States

| Interaction | Behavior |
|-------------|----------|
| Create key | Opens dialog -> enter label -> submit -> loading spinner on button -> success shows key -> copy -> done |
| Copy key | Click copy icon -> key copied to clipboard -> icon changes to checkmark for 2s -> sonner toast "API key copied to clipboard" |
| Revoke key | Click "Revoke" -> AlertDialog opens -> confirm -> loading spinner -> row updates to revoked state with badge |
| Max keys reached | "Create API Key" button disabled, tooltip shows max-keys-reached message |
| Keyboard | Dialog traps focus, Escape closes (except key-created state), Enter submits form |
