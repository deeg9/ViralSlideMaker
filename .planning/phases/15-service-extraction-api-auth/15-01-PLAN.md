**3. Create `src/lib/crypto/hash.ts`** -- SHA-256 hashing via Web Crypto API (per AAUTH-04):
```typescript
export async function hashApiKey(key: string): Promise<string> {
  const encoder = new TextEncoder()
  const data = encoder.encode(key)
  const hashBuffer = await crypto.subtle.digest('SHA-256', data)
  const hashArray = Array.from(new Uint8Array(hashBuffer))
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('')
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> API route | Untrusted HTTP requests with Bearer tokens cross into server |
| API route -> Supabase | Authenticated server-side queries using admin client (service role) |
| API route -> Upstash | Rate limit checks via HTTP to external Redis service |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Spoofing | API auth | mitigate | Validate Bearer token via SHA-256 hash lookup in route handler (not middleware per CVE-2025-29927) |
| T-15-02 | Spoofing | API key brute force | accept | 36-char key = 192 bits entropy; rate limiting by IP not implemented but key space is sufficient |
| T-15-03 | Information Disclosure | API key logging | mitigate | Never log raw keys; only log prefix (vsl_XXXX). hashApiKey before any storage operation |
| T-15-04 | Information Disclosure | key_hash in API response | mitigate | listApiKeys strips key_hash from response, returns only prefix + metadata |
| T-15-05 | Denial of Service | Rate limit bypass via key rotation | mitigate | Max 3 keys per user caps total throughput at 3x tier limit |
| T-15-06 | Denial of Service | Credit exhaustion | mitigate | Rate limiting + existing credit balance checks before expensive AI operations |
| T-15-07 | Elevation of Privilege | Next.js middleware bypass | mitigate | Auth in route handler per CVE-2025-29927, never in middleware |
| T-15-08 | Tampering | Request body manipulation | mitigate | Zod schema validation on all API request payloads before processing |
</threat_model>
