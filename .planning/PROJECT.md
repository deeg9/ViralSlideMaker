# TikTok Slideshow Creator

## What This Is

An AI-powered slideshow and video creator that generates TikTok-ready vertical content from a simple text prompt. Users enter a topic or product description, Claude auto-generates slide content (hook text, body copy, image queries, closing lines), images are sourced from stock APIs or user uploads, and the result is a polished 9:16 video with text overlays and transitions — ready to export and post on TikTok or Instagram Reels. Think BigMotion, but built as a personal tool first, then opened as a public SaaS.

## Core Value

Type a topic, get a ready-to-post TikTok slideshow video — fully generated by AI, editable in a full-featured slide editor, exportable as MP4.

## Context

- **Inspiration**: BigMotion AI (app.bigmotion.ai) — similar product with project selector, text preferences input, image gallery, multi-slide preview, generate + export buttons
- **Design inspiration**: 21st.dev — clean, minimal aesthetic
- **Prior research**: Remotion (React video framework) is the most mature option for programmatic video creation. Has TikTok-specific templates, editor starter kits, and is free for individuals/small teams. Also considered Python+FFmpeg — viable for backend rendering but less polished for browser preview.
- **Key open-source references**: remotion-dev/template-tiktok, reactvideoeditor/free-react-video-editor, tanersener/ffmpeg-video-slideshow-scripts

## Constraints

- **Platform**: Web-first (Next.js), iOS App Store later (Expo/React Native sharing components)
- **Rendering**: RunPod serverless for video rendering — containers spin up for Remotion/FFmpeg renders, scale to zero when idle. Frontend never renders video locally.
- **AI**: Claude API for all content generation (slide text, hooks, image search queries)
- **Images**: Pexels API (free, no attribution required for most uses) + user uploads. No AI image generation in v1.
- **License**: Remotion free tier covers solo/small team usage
- **Design**: Clean + minimal aesthetic, not dark/flashy
