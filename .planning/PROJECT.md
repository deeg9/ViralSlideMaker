# TikTok Slideshow Creator

## What This Is

An AI-powered carousel/slideshow image creator that generates TikTok and Instagram-ready slide images from a simple text prompt. Users enter a topic or product description, Claude auto-generates slide content (hook text, body copy, image queries, closing CTA), images are sourced from Pexels stock photos or user uploads, and the result is a set of polished 9:16 slide images with text overlays — ready to download and upload as a TikTok/Instagram carousel. Think BigMotion's slideshow tool, but outputting individual images for carousel posts rather than video. Built as a personal tool first, then opened as a public SaaS.

## Core Value

Type a topic, get a set of ready-to-post carousel slide images — fully generated by AI, editable in a full-featured slide editor, downloadable as individual images or ZIP.

### Out of Scope

- MP4 video export — output is carousel images, not video. Revisit if user demand emerges.
- Remotion / video rendering framework — not needed for image output
- RunPod / GPU rendering — server-side image rendering is lightweight, no GPU needed
- AI-generated images (DALL-E, Flux) — stock photos are free and look more natural for slideshows
- Auto-posting to TikTok/Instagram — complex OAuth, defer to v2
- Music/audio — not applicable to image carousels
- AI voiceover / TTS — not applicable to image output
- AI avatars / talking heads — different product category
- Video clip support — images only
- Real-time collaboration — solo creator tool
- Complex timeline editor — slide-based, not timeline-based
- Native iOS app — web first, Expo/React Native port planned for v2
- Watermarks on free tier — use usage limits instead if monetizing

## Context

- **Inspiration**: BigMotion AI (app.bigmotion.ai) — similar product with project selector, text preferences input, image gallery, multi-slide preview, generate + export buttons
- **Design inspiration**: 21st.dev — clean, minimal aesthetic
- **Output format**: Individual 9:16 images (1080x1920) that users upload as TikTok/Instagram carousels. Not video.
- **Key insight**: TikTok is penalizing low-quality slideshow spam. Quality AI-generated content with compelling hooks stands out. This validates the "smart hooks" differentiator.
- **Architecture insight**: Server-side image rendering means the same API serves both web and future iOS app — the mobile client just calls endpoints.

## Constraints

- **Platform**: Web-first (Next.js), iOS App Store later (Expo/React Native sharing components)
- **Rendering**: Server-side image generation (Puppeteer/Sharp) — consistent quality, reusable API for iOS
- **AI**: Claude API for all content generation (slide text, hooks, image search queries)
- **Images**: Pexels API (free, no attribution required for most uses) + user uploads. No AI image generation in v1.
- **Design**: Clean + minimal aesthetic, inspired by 21st.dev
