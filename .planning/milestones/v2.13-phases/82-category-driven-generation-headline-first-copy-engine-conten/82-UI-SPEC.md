# Phase 82 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope of UI delta (small):** Phase 82 inserts ONE new control — a content-category
selector — into the existing `src/components/slides/generation-form.tsx`, and filters
the existing `TemplatePicker` by the selected category. No page redesign, no new design
system. All values below are extracted from the existing creation form so the new
control is visually indistinguishable from the form sections that already ship
(Presentation Prompt, Copy style, Select Visual Style, Number of Slides, Background
Images, Advanced Options). 82-CONTEXT.md locked the picker behavior; no open questions.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — existing bespoke Tailwind utility styling in `generation-form.tsx`; do NOT introduce shadcn for this control |
| Preset | not applicable |
| Component library | none — `@/components/ui/icon` (`Icon`) wraps Material Symbols; reuse it |
| Icon library | Material Symbols via the project `Icon` component (NOT lucide, despite `components.json`; the creation form uses `Icon` exclusively) |
| Font | Inherited app font (no font declaration in this control) |

The category selector matches the existing **collapsible section** pattern used by
"Select Visual Style", "Number of Slides", "Background Images": an uppercase bold
section header button with an `expand_more` chevron, and the existing **3-up card grid**
pattern (`grid grid-cols-3 gap-3` with bordered selectable cards) used by the
"Background Images" toggle. Reuse those patterns verbatim.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | `ml-1` header nudge, icon gaps |
| sm | 8px | `gap-2` chevron-to-label |
| md | 16px | `gap-3` / `gap-4` card grid gaps, `mt-4` section reveal padding |
| lg | 24px | `p-4` (16px) card inner padding rounds up into this band |
| xl | 32px | `gap-8` between form sections (`flex flex-col gap-8` on the `<form>`) |
| 2xl | 48px | not used in this control |
| 3xl | 64px | not used in this control |

Exceptions: card inner padding is `p-4` (16px) per the existing Background Images cards;
the category control must use the SAME `p-4` so the two grids align visually.

## Color

Existing bespoke maroon palette (from `generation-form.tsx`). Do not introduce new hues.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Card backgrounds, form surface |
| Secondary (30%) | `#fff0f0` | Selected-card fill tint; hover wash |
| Accent (10%) | `#3d0000` (maroon) | Selected card border + selected label/icon text; section CTA color |
| Muted text | `#7d6161` | Section header label, unselected card label/icon, sub-labels |
| Muted border | `#dbc1bc` (at `/20`–`/40` opacity) | Unselected card border, hover border |
| Destructive | `#b91c1c` (`text-red-700` / `bg-red-50` / `border-red-200`) | Error states only — not used by this control |

Accent reserved for: the **selected category card** (border `#3d0000`, fill `#fff0f0`,
label + icon text `#3d0000`) — exactly as the Background Images cards select. Never
apply accent to unselected or disabled cards.

**Coming-soon / disabled categories** (Health & Wellness, Beauty — framework-only this
phase): render as a card at reduced affordance — `opacity-50`, `cursor-not-allowed`, a
10px `#7d6161` "Coming soon" sub-label, not clickable. They may also simply be omitted;
either is acceptable per SPEC R6. If shown, they must clearly read as non-selectable.

## Interaction & Placement Contract

- **Placement:** the `Content Category` collapsible is inserted **above "Select Visual
  Style"** (and above the "Copy style" collapsible is acceptable too) — the user picks
  *what kind of content* before *what it looks like*. It must NOT replace or reorder the
  existing five sections; it is a sixth peer section in the same `gap-8` stack.
- **Default open:** the section defaults **open** on first paint (like Select Visual
  Style / Number of Slides), so the new capability is discoverable.
- **Selection model:** single-select, exactly one category active at all times; `News`
  is the initial value. Mirrors the Background Images radio-card pattern.
- **Category → picker coupling:** changing the category re-filters the `TemplatePicker`
  to that category's `templateIds` subset. When the filtered subset no longer contains
  the currently-selected `templateId`, snap `templateId` to the category's default
  (first entry in its `templateIds`) — never leave the picker on a now-hidden template.
- **No raw fallback (SPEC R7):** there is no "no category" / "surprise me" card; a
  category is always selected, so generation can never fall through to the silent
  `highlight-bar` path.
- **Disabled state during generation:** every category card sets `disabled={isPending}`
  and `disabled:opacity-50`, identical to the Background Images cards, so the control
  locks while a generation is in flight.
- **Accessibility:** the section header button keeps `aria-expanded`; each category card
  is a `<button type="button">` with an `aria-pressed` reflecting selection (the
  Background Images cards lack `aria-pressed` today — the new control should ADD it, as
  a small correctness improvement, without restyling). Selected state must be conveyed
  by more than color alone — the accent border + fill tint together satisfy this.
