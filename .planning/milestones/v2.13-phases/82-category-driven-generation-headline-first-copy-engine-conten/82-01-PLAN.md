<objective>
Make `body_text` optional end-to-end and add an optional per-slide `accessory_label` field so headline-only slides become first-class. This is the schema foundation Wave 2 generation wiring and Wave 3 tests depend on.

Purpose: Today `body_text` is `required` in the Gemini `responseSchema` and a non-optional `z.string()` in Zod — headline-only slides cannot validate. This plan flips both, adds the small accessory-label field (kicker / one-liner), and updates the legacy→`text_boxes` adapter and `validateAndRepair` so absent body text and the new label flow through cleanly without breaking the ~50 pre-Phase-82 carousels.

Output: `body_text` optional in Zod + dropped from the Gemini slide-level `required`; a new optional `accessory_label` string in both schemas; `legacyToTextBoxes` mapping `accessory_label` to a distinct small top-anchored `role: 'custom'` text box; `validateAndRepair` body-checks guarded for absence; a new unit test file covering all of the above.
</objective>
