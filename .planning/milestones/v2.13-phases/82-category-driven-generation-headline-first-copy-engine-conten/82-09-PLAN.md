<objective>
Fix **Gap E** from the R10 round-2 visual sign-off (the renderer breaks words
mid-word) and wire the Plan 08 caption-card-aware auto-fit into all three render
paths so the headline fills the k2n caption card.

GAP E ROOT CAUSE (verified): the shared segment renderer `renderSegments`
(`resolve-overlay.ts:168-237`) sets `overflowWrap: 'break-word'` on EVERY segment
span (both the pill branch, line 204, and the plain branch, line 229). For a news
headline, `promoteNewsHeadline` derives ONE segment per WORD — so each span holds
a single word. `overflow-wrap: break-word` on a single-word span breaks THAT word
mid-word when it is wider than the container ("ANNOUNCE" + orphaned "S" — ref
`~/Desktop/Screenshot 2026-05-17 at 3.04.57 PM.png`). The hook container itself is
`display: flex; flex-wrap: wrap` so it ALREADY wraps between word-spans at spaces;
the per-span `break-word` only ever splits a word — it is never needed for
inter-word wrapping. Removing it makes words wrap whole-word only.

NOTE the existing comments on lines 199-202 / 226-228 deliberately chose
`overflow-wrap: break-word` over the deprecated `wordBreak: 'break-word'` (which
breaks even harder). The Gap-E fix goes one step further: with Plan 08's auto-fit
guaranteeing the longest word always fits the box, NO mid-word break is needed at
all — so the per-span wrap rule becomes whole-word (`overflowWrap: 'normal'`).

GAP D RENDER WIRING: Plan 08 added `fitHeadlineToBox` + `captionCardBox` to
`hook-fit.ts` and made `promoteNewsHeadline` size the headline to the default news
box at generation time. But the user's target (`~/Desktop/Screenshot 2026-05-17 at
3.06.22 PM.png`) is the headline contained in the BOTTOM BLACK CAPTION CARD — and
the k2n caption card is draggable/resizable, so the box the headline must fill is
only known at render time from `resolveCaptionBar`. This plan adds the render-time
re-fit: when a slide has a caption card enabled, the renderer re-computes the hook
font size to fit the caption card's resolved box.

FIX:
1. **`resolve-overlay.ts` — `renderSegments` wraps whole-word.** Change the
   per-segment span style from `overflowWrap: 'break-word'` to
   `overflowWrap: 'normal'` (the CSS default — never break inside a word) in BOTH
   the pill branch and the plain branch. Keep `maxWidth: '100%'`. Update the
   anti-`wordBreak` comments to explain the new whole-word rule.
2. **`resolve-overlay.ts` — `resolveNewsHeadlineFit` shared helper.** A new pure
   exported function that, given the slide's resolved caption bar, the hook text,
   the currently-resolved hook font size, and whether the slide is a news-layout
   slide, returns the font size the headline should render at: if a caption card
   is enabled, return `fitHeadlineToBox(hookText, captionCardBox(resolvedBar))`;
   otherwise return the incoming size unchanged. This is the SINGLE source of
   truth all three render paths call (TPLREND-05).
3. **Wire `resolveNewsHeadlineFit` into all three render paths** so the hook font
   size honors the caption card.
</objective>
