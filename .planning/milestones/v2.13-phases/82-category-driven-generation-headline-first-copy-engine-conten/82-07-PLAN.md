<objective>
Fix Gap B and Gap C from the R10 visual sign-off. Both live in the News generation pipeline and are tightly coupled (a single post-generation transform handles both), so they share one plan.

**Gap B — News does not highlight keywords.** Generated news slides render plain white text. Two root causes, both verified:
  1. `categories/news.ts` tells Gemini to mark words `accent: true`. But `accent: true`
     alone renders as two-color *text* (`resolve-overlay.ts:178` — `seg.accent ? accentColor : baseColor`).
     The user's target (`~/Desktop/Screenshot 2026-05-17 at 2.13.25 PM.png`) is **pill**
     highlights — a colored background behind the word. The renderer's pill branch
     (`resolve-overlay.ts:188`) only fires when a segment carries `highlightColor`.
     The editor's `toggleAccent` (`ActiveTextBoxCard.tsx:168-188`) produces exactly that:
     `{ accent: true, highlightColor: effectiveAccentColor, highlightStyle: 'pill' }`.
     News generation must emit the same shape.
  2. The user's test slide showed NO highlight at all — segments were dropped or not
     emitted. ROOT CAUSE FOUND: Gemini non-compliance — `hook_segments` is OPTIONAL in
     both the Zod schema (`schemas.ts:31-34`) and the Gemini response schema
     (`generate-slides.ts:67`), with no `required` entry, so Gemini can (and on the
     user's run did) return a headline with no `hook_segments` array. `validateAndRepair`
     does NOT strip news segments (its strip is `templateId === 'documentary'` only) —
     it simply has nothing to work with when Gemini emits none. The fix needs a
     deterministic post-generation fallback that derives `hook_segments` from
     `hook_text` when Gemini emits none, so a news headline is NEVER left plain.

**Gap C — generated headline starts too small.** Generation never sets `font_size`.
News headlines fall back to the template default (`news-cyan` `hookFontSize: '124px'`).
`legacyToTextBoxes` (`text-box-adapter.ts:108`) only reads `overrides.hook_font_size`.
News headline-only slides must generate with a large `hook_font_size` so the headline
dominates like the reference.

Fix (one shared transform): a new pure module `promote-news-headline.ts` exporting
`promoteNewsHeadline(carousel)` that, per slide: (B1) for every `hook_segments` entry
with `accent: true`, sets `highlightColor` to the news template's accent color and
`highlightStyle: 'pill'`; (B2) when a slide has NO `hook_segments` (or none accented),
derives them deterministically from `hook_text` — split on whitespace into word runs,
mark the longest non-connector word(s) as accented pills — so every news headline gets
>= 1 pill; (C) sets `style_overrides.hook_font_size` to a large value (e.g. 200) so the
headline dominates. `generateSlideContent` invokes it for `category === 'news'` AFTER
`CarouselSchema.parse` and BEFORE `legacyToTextBoxes` so the pills + size flow into
both the legacy fields (read by both renderers) and the derived `text_boxes`.

NOTE: Gemini's `accent: true` text-prompt instruction in `news.ts` stays — the
post-generation transform PROMOTES whatever Gemini emits. The prompt is also tightened
to make `hook_segments` non-optional in spirit (the schema stays optional for back-compat;
the prompt strengthens the instruction).
</objective>
