# Milestone v2.1: Text Effects

**Status:** SHIPPED 2026-04-07
**Phases:** 19-21
**Total Plans:** 5

## Overview

Added text shadow, outline, and background highlight effects to make text stand out over images. Per-element controls for hook, body, and custom text boxes. All effects Satori-compatible using native CSS properties (textShadow, WebkitTextStroke). Zero new dependencies.

## Milestone Summary

**Key Decisions:**
- Satori natively supports textShadow and WebkitTextStroke -- no duplicate-element workarounds needed (validated via spike)
- Use 8-digit hex colors (#00000080) not rgba() to avoid Satori Issue #441
- Nested TextEffects interface (not flat fields) to avoid 18+ property explosion
- Tight highlight falls back to full-width in Satori (lacks box-decoration-break: clone)
- Per-element independence: hook, body, and each custom text box have independent effects

**Issues Resolved:**
- Confirmed Satori CSS support gap was smaller than assumed -- native support eliminated 40% of estimated work

**Issues Deferred:**
- Visual checkpoint: editor controls need manual browser testing
- Gradient text, neon glow, blur effects require Playwright rendering switch

**Technical Debt:**
- Pre-existing: Satori renderer hardcodes font-weight instead of using resolved values
- Tight highlight Satori fallback means export differs from preview for tight mode
