## Phase 59 — Corner Resize Handles + Font-Scale

**Goal:** Ship corner-drag-to-scale-font-and-width on text boxes (hook, body, custom) with side-handle width-only behavior preserved, top/bottom handles disabled, Shift+corner width-only escape hatch, single undo entry per gesture, WCAG 2.5.8 AA touch target compliance, and the v2.9 TPLREND-05 renderer parity invariant intact across all 3 render paths.

**Plans:**
- **59-01** — Enable corner handles. Flipped `enableResizing` to corners-on / top-bottom-off in `slide-preview.tsx` (3 `<Rnd>` call-sites: hook, body, custom). Added 12×12 visual handle + 24×24 hit zone via `inset: -6px` wrapper. Added `nwse-resize` (TL/BR) and `nesw-resize` (TR/BL) cursors. Captured `oldWidthPx` + `oldFontSize` snapshot in `onResizeStart` for consumption in 59-02. Addresses RESIZE-01, RESIZE-02, RESIZE-03, A11Y-01, A11Y-02. **Commits:** 5af6190, 9649fb6, ec93925.
- **59-02** — Dispatch font_size on corner. Added module-level helpers `ROLE_FONT_BOUNDS`, `scaleFontSizeOnCorner`, `isCornerDir`. Each `onResizeStop` branches on `dir`: corner → compute `widthRatio`, dispatch `font_size` alongside `width`; side → dispatch `width` only. Routed through `slide-editor.tsx` new `handleSizeChange` + `handleCustomTextSizeChange`; legacy `handleWidthChange` preserved for back-compat. Wired through `slide-canvas.tsx` (2 forwarding props). Addresses FONTSCALE-01 through FONTSCALE-04. **Commits:** decf591, a89c2c6, 920158e.
- **59-03** — Tests. Added 13 new tests pinning UNDO-01 (60-tick → 1 history entry), PARITY-01 (3-renderer byte-identity for corner-dragged values), PARITY-02 (zero handle DOM in non-editable branch), FONTSCALE-02 (clamp behavior), FONTSCALE-04 (hook-fit override regression). 47/47 in the 3 phase test files green. Manual iPhone Safari touch QA gate deferred per orchestrator decision. **Commits:** e57b8b9, 7408ecf, 1e63849, d4994ac.
- **59-04** — Shift+corner = width-only escape. 3 `onResizeStop` handlers gain `&& !(e as MouseEvent).shiftKey` guard. Added unit + integration tests for the modifier behavior. Custom-image `<Rnd>` block byte-identical (image-only handle stays untouched). Addresses RESIZE-04. **Commits:** 1ff44f6, a4ea03d, cde0940.

## Decisions honored

- Stayed on `react-rnd@10.5.3` — 6-line `enableResizing` flip, no library swap.
- No schema change. Persisted via existing `font_size` + `position.width`.
- Past-cap = box keeps growing, font caps (Canva pattern, forgiving > honest).
- Shift+corner = width-only escape (5-line addition).
- WCAG 2.5.8 AA — 24×24 CSS px hit zones via wrapper.
- TPLREND-05 invariant preserved end-to-end. Three renderer files byte-identical to base SHA.
