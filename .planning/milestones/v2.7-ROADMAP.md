## Goal

Replace the current 5 visually weak templates with a richer template system + 3 new "magazine-style" premium templates that match modern viral creator aesthetics. Reference design: Murphy Campbell folk-singer carousel (B&W photo + topic chip top-left + page counter top-right + mint-highlighted headline + bottom text card).

**Why now:** First Claude Desktop end-to-end test on 2026-04-28 surfaced rendered carousels that look unprofessional next to modern creator references. MCP integration works mechanically (v2.6 shipped) but template visual quality is the next bottleneck for product-quality output.

## What Shipped

- **8 templates** (5 legacy preserved byte-identical + 3 new premium): `highlight-bar`, `news-drop`, `news-cyan`, `y2k-pop`, `bold-yellow`, `magazine-bold` (Murphy reference), `tr3nding-news`, `documentary`
- **Extended `SlideTemplate` type system**: `overlays?: TemplateOverlay[]`, `backgroundMode?: 'color' | 'image-bleed' | 'image-with-bottom-card'`, `aiVoiceNote?: string`. `TextSegment.highlightColor` and `highlightStyle` for per-word mint pills.
- **Shared `resolve-overlay.ts` module**: pixel-fidelity rendering tokens (slot anchors, pill specs, background composition) consumed by BOTH Satori and React preview — guarantees TPLREND-05 zero-drift parity.
- **Renderer Satori + React preview parity**: full-bleed photo, overlay zones (chip/counter/mid-pill/bottom-card/free), dynamic page-counter, per-word highlight pills. DOM-order layer stack documented in 9 layers.
- **Phase 44 validator**: `validateTemplateRegistry` runs at module load — fails fast in `npm run build` on any overlay misconfig.
- **AI prompt tuning**: length caps (12-word hooks / 35-word bodies, premium-tier only), 28-entry curated typo list with retry-once-on-detection, AI-emitted `highlightColor` per segment driven by `template.accentColor`, per-template `aiVoiceNote` for tonal differentiation.
- **8 template thumbnail PNGs** at `public/templates/<id>.png` (regenerated via `npm run thumbs`).
- **Picker DOM regression test** locks TPLTHUMB-02 — no template falls back to a swatch.
- **51 new tests** added across 3 phases (26 resolve-overlay unit + 10 Satori snapshot + 15 React DOM signature in Phase 45; +21 Phase 46 + 11 Phase 47 + 4 Phase 48).
