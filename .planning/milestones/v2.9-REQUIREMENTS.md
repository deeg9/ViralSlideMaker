# Requirements: v2.9 Viral Visual Quality (ARCHIVED)

**Status:** SHIPPED 2026-05-01
**Final tally:** 53 / 53 requirements satisfied (100%). Zero unsatisfied. Zero orphans. Zero partial.

**Milestone goal:** Upgrade the visual output of AI-generated carousel slides so they look like what's actually winning on TikTok and Instagram in early-to-mid 2026 — replicating proven patterns from successful creators rather than guessing.

**Research grounding:** Aesthetics of Photography "Viral Visual Grammar of US Instagram in 2026"; Canva "Imperfect by Design 2026"; It's Nice That graphic trends 2026; Mosseri Jan 2026 "rawness is proof"; verified Satori constraints (issues #573, #162, #712); Imagen 4 Fast pricing (Google AI docs); right-of-publicity precedent (Reface/Kyland Young, 9th Cir.).

**Success metric:** ZIP download rate per created carousel — proxy for "good enough to ship." Baseline captured at Phase 54 (`v2.9-METRIC-BASELINE.md`); ship-gate non-regression verified at Phase 58.

**Out-of-scope by user decision (deferred to v3.0+):** legacy schema sunset, `stylize-image.ts`, Pangram Pangram fonts, Variable fonts, CANVAS-03 (Layers mini-list), AIGEN-01 (native Gemini `text_boxes[]` prompt), render-parity-grid React-preview half, live Gemini diversity-gate wiring.

## TREAT — Photo treatment pipeline

- [x] **TREAT-01** — `src/lib/photo-treatment/treat.ts` exposes `treatPhoto(sourceUrl, spec)` returning `{ url, palette }`. Uses sharp for transforms; idempotent via SHA-256 cache key of `(sourceUrl + spec)`. Supports presets: `bw`, `duotone-cream`, `duotone-cobalt`, `contrast-bump`.
- [x] **TREAT-02** — Treated assets stored in new public Supabase Storage bucket `slide-backgrounds-treated`. Cache hit returns existing URL without re-processing.
- [x] **TREAT-03** — Sharp module config locked: `sharp.cache(false)` and `sharp.concurrency(1)` set at module load to prevent serverless memory fragmentation.
- [x] **TREAT-04** — Generation pipeline writes `treatedUrl` to `slide.background_url` and the original Pexels/Imagen URL to new field `slide.original_source_url`. Re-treating starts from `original_source_url`, never compounds.
- [x] **TREAT-05** — Pure unit tests for treatment functions (no DB) verify byte-identical output for the same `(sourceUrl, spec)` pair across two invocations.
- [x] **TREAT-06** — `slide-backgrounds-treated` bucket has 7-day retention policy on assets without an associated project (intermediate cache cleanup via `pg_cron`).

## SLOP — AI-slop guardrails

- [x] **SLOP-01** — Imagen prompt mandatory addendum: "Do not generate gradient backgrounds. Do not generate glossy 3D objects or abstract color blobs. Generate documentary-style photographs with naturalistic lighting." Applied at every Imagen call site.
- [x] **SLOP-02** — Pexels query addendum: append "natural lighting, candid, editorial, portrait" and exclude terms `meeting, office, team, smiling, diverse group` from the search query string before hitting Pexels API.
- [x] **SLOP-03** — Template validator requires `bodyFontFamily: string` as non-nullable on every premium-tier template. Inter-as-default falls through is impossible by construction; templates must declare a body font explicitly.
- [x] **SLOP-04** — AI hook generation system-prompt addendum: "Do not start hooks with 'In a world where', 'Did you know', 'Imagine if'. Vary hook openings across slides in the same carousel."
- [x] **SLOP-05** — Existing 8 templates audited: any template defaulting to Inter as `bodyFontFamily` updated to declare a non-Inter font (`magazine-bold` and `documentary` flipped Inter → Plus Jakarta Sans).

## AIROLE — Slide-role-aware AI generation

- [x] **AIROLE-01** — Gemini slide-generation response schema extends each slide with `role: 'cover' | 'reframe' | 'support' | 'pivot' | 'close'`. First slide is always `cover`; last slide is `close`; middle slides distributed across `reframe`/`support`/`pivot` based on carousel length.
- [x] **AIROLE-02** — System prompt includes per-role copy guidance (cover = pattern-interrupt hook ≤8 words; reframe = "wait, but" tension; support = concrete evidence/example; pivot = unexpected angle; close = action / CTA / bookmark prompt). Diversity gate advisory only in v2.9 (D-14) — does not fail CI; live Gemini wiring deferred to v3.0+.
- [x] **AIROLE-03** — Gemini response schema gains `template_id_override?: string` (closed enum, registry-validated). AI may pick a different template per slide for visual rhythm; null = use project template.
- [x] **AIROLE-04** — Existing premium-tier guardrails (length caps, typo gate) preserved; v2.7 audit baseline (19/19 reqs) re-verified after prompt change.
- [x] **AIROLE-05** — Server-side validator: if `role` field missing or invalid, default to legacy flat distribution. Never throws — user always gets a usable carousel.

## Locked Decisions (from research synthesis + user input 2026-05-01)

- **Photo treatment baked server-side via sharp** — CSS filters silently break Satori PNG export (vercel/satori#573). Pre-render is both correct and the only path.
- **Imagen 4 Fast** (`imagen-4.0-fast-generate-001`) replaces current Imagen 3. Cheaper ($0.02 vs $0.04/image), 10× faster, better text rendering. One-line config change. Verified live.
- **5 phases (54-58)** chosen over 7 (Architecture proposed) or 5 with different boundaries (Stack proposed). Phases group by build-order dependency.
- **All 3 new templates free** for all users — pre-PMF, top-of-funnel sharing > premium gating.
- **`match-photos-to-slides.ts` ships** premium-gated in Phase 58 (last). Architecturally clean; cost concerns mitigated by `MAX_PHOTOS=8` + cache + timeout.
- **`stylize-image.ts` deferred** to post-v2.9. File stays in repo; not wired into pipeline. Re-evaluate post-PMF as one-shot user action with face-detection refusal.
- **Brutalist-Grid added to scope** beyond Top-5 features (user expansion 2026-05-01) — third differentiation template family.
- **Success metric = ZIP download rate.** Baseline measured at Phase 54 start; ship gate at Phase 58 verifies non-regression.
- **No Pangram fonts.** Free Google Fonts only — Playfair Display, DM Serif Display, Bebas Neue, Archivo Black, Plus Jakarta Sans, Space Grotesk, Manrope.
- **Diversity gate advisory only** (D-14) — does not fail CI. Live Gemini wiring deferred to v3.0+.
