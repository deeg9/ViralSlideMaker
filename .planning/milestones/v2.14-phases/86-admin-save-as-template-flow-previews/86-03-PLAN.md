<objective>
Make the template picker render a DB template's saved cover-snapshot PNG:
1. Add an optional `preview?: string` field to the `SlideTemplate` type and
   carry the `templates.preview` DB column through `dbRowToSlideTemplate`.
2. Add a `TemplateTilePreview` component that renders the `preview` PNG via an
   `<img>` when present, falling back to the existing live `<SlidePreview>`
   path otherwise — and wire the picker tiles to use it.

Purpose: this plan delivers ADMIN-02 — a DB template's picker tile is visually
faithful to the source carousel because it shows the actual cover snapshot
(photo included), which a synthetic `sample`-only payload could never capture.
Render parity (TPLREND-05) is preserved: the 13 code templates leave `preview`
undefined and render via the unchanged `<SlidePreview>` path — zero regression.
Output: the extended `SlideTemplate` type + mapper, the `TemplateTilePreview`
component + tests, and the picker wired to it.
</objective>
