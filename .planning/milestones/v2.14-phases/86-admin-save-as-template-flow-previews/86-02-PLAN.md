<objective>
Build the admin Save-as-Template authoring flow end to end:
1. `src/lib/templates/slug.ts` — a pure `templateSlug` deriving a URL-safe id
   from the template name.
2. `POST /api/admin/templates` — the session-authed, admin-gated save endpoint:
   re-checks admin, loads the admin's own source carousel, extracts the recipe
   + flat style, renders + uploads the cover preview PNG, and writes the full
   `templates` row in ONE service-role insert with a collision-safe slug id.
3. The `(admin)` route group: `(admin)/layout.tsx` (admin-auth wrapper,
   server-side redirect for non-admins) + `(admin)/templates/save/page.tsx`
   (loads the admin's own projects) + the client `save-template-form.tsx`.

Purpose: this plan delivers ADMIN-01 — an admin can save a carousel as a
template through a role-gated flow; a non-admin cannot reach the page OR the
endpoint. The save extracts a Phase 84 recipe so the minted template is
recipe-driven at generation time (Phase 85) — the milestone ties together here.
Output: the slug helper + tests, the save endpoint + tests, and the `(admin)`
route group with its page and form.
</objective>

  <files>src/app/api/admin/templates/route.ts</files>
  <read_first>src/app/api/admin/seed-explore/route.ts, src/lib/auth/admin.ts, src/lib/ai/layout-recipe-extract.ts, src/lib/render/preview-render.ts, src/lib/render/templates/registry.ts, src/lib/render/templates/index.ts, src/lib/ai/categories/index.ts, src/lib/supabase/admin.ts, src/lib/supabase/server.ts, src/lib/templates/slug.ts</read_first>
  <action>
Create a NEW route handler `src/app/api/admin/templates/route.ts` exporting an
async `POST(request: Request)`. Set `export const maxDuration = 60` (the
synchronous Satori render needs headroom — mirror `/api/render`).

Step-by-step (return early with a JSON error + status on every failure path):

1. **Admin gate (ADMIN-01).** `const supabase = await createClient()` (the
   session-aware client from `@/lib/supabase/server`). `const admin = await
   requireAdmin(supabase)`. If `admin` is `null` → return
   `NextResponse.json({ error: 'Forbidden' }, { status: 403 })`. This is the
   endpoint-side mirror of the page gate — a non-admin session OR no session
   gets 403. No bearer token.

2. **Parse + validate the body.** Read JSON: `{ projectId: string, name:
   string, category: string }`. Validate with a small zod schema OR inline
   checks: `projectId` non-empty string; `name` non-empty trimmed string;
   `category` must be one of `CONTENT_CATEGORIES` (`news` / `facts`) — import
   `CONTENT_CATEGORIES` from `@/lib/ai/categories` and reject anything else
   with a 400 (closed-enum invariant). On any invalid field return
   `NextResponse.json({ error: '<specific message>' }, { status: 400 })`.

3. **Load the source carousel — the admin's OWN project only.** Use
   `getProject(supabase, admin.id, projectId)` from `@/lib/services/projects`
   (it filters `.eq('user_id', userId)` so another user's project id resolves
   to an error). Wrap in try/catch; on error or no row return
   `NextResponse.json({ error: 'Carousel not found' }, { status: 404 })`.
   Extract `slides = project.slide_data as Slide[]`. If `slides` is empty or
   `slides[0]` is missing → 400 `'Carousel has no slides'`.

4. **Resolve the source template.** `const sourceTemplate = await
   resolveTemplate(project.template_id ?? 'highlight-bar')` from
   `@/lib/render/templates/registry`.

5. **Extract the recipe + flat style (Phase 84).** `const { recipe, flatStyle
   } = extractLayoutRecipe(slides, sourceTemplate)` from
   `@/lib/ai/layout-recipe-extract`. `extractLayoutRecipe` never throws.

6. **Render the cover preview PNG (ADMIN-02).** `const origin = new
   URL(request.url).origin`. `const previewBuffer = await
   renderCoverPreviewPng(slides[0], sourceTemplate, { slideIndex: 0,
   totalSlides: slides.length, topic: project.topic ?? undefined }, origin)`
   from `@/lib/render/preview-render`. Wrap in try/catch; on render failure
   return `NextResponse.json({ error: 'Preview render failed' }, { status: 500
   })`.

7. **Derive a collision-safe template id.** `const adminClient =
   createAdminClient()` (service-role, from `@/lib/supabase/admin`). Compute
   `let id = templateSlug(name)`. A collision is: the id is a code-template id
   (`TEMPLATE_IDS` from `@/lib/render/templates/index`) OR an existing
   `templates` row id. Check the DB id with
   `adminClient.from('templates').select('id').eq('id', id).maybeSingle()`.
   While `id` collides (loop up to ~5 attempts), reassign `id =
   withSuffix(templateSlug(name))`. A code-template id ALWAYS forces a suffix
   — never shadow a code template (code wins per Phase 83).

8. **Upload the preview PNG.** Path `${admin.id}/${id}.png`.
   `await adminClient.storage.from('template-previews').upload(path,
   previewBuffer, { contentType: 'image/png', upsert: false })`. On upload
   error return 500 `'Preview upload failed'`. Then `const { data: pub } =
   adminClient.storage.from('template-previews').getPublicUrl(path)` →
   `previewUrl = pub.publicUrl`.

9. **ONE service-role insert of the full row.**
   `await adminClient.from('templates').insert({ id, name: name.trim(),
   category, flat_style: flatStyle, layout_recipe: recipe, created_by:
   admin.id, preview: previewUrl }).select('id').single()`. On insert error:
   best-effort remove the orphan preview
   (`adminClient.storage.from('template-previews').remove([path])`) and return
   500 `'Template insert failed'`.

10. **Success.** Return `NextResponse.json({ id, name, previewUrl }, { status:
    201 })`. The picker reflects the new template within the Phase 83 registry
    TTL window (≤60s) — accepted; no explicit cache bust.

Add `import type { Slide } from '@/lib/types/slide'`. Add a file comment:
admin-gated (ADMIN-01) via the shared `requireAdmin` session check; the FULL
row is written in one service-role insert; the slug id never shadows a code
template; render parity is preserved via the shared `renderCoverPreviewPng`.
  </action>
