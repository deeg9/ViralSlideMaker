  <action>
Create a NEW file `src/lib/auth/admin.ts`. This is the single reusable admin
helper — both the `(admin)` layout loader and the save endpoint import from
here (NEVER re-implement the check inline anywhere).

Export TWO functions plus a private allowlist parser:

1. A private `parseAdminAllowlist(): Set<string>` that reads
   `process.env.ADMIN_USER_IDS` (a comma-separated string of Supabase user
   ids), splits on `,`, trims each entry, drops empties, and returns a
   `Set<string>`. An unset/empty env var yields an EMPTY set.

2. `export function isAdminUser(userId: string | null | undefined): boolean`
   — returns `true` ONLY when `userId` is a non-empty string AND, after
   trimming, is present in `parseAdminAllowlist()`. A null/undefined/empty
   `userId` returns `false`. An empty allowlist returns `false` for everyone
   (FAIL-SAFE — when the env var is unset the admin surface is fully closed,
   never open).

3. `export async function requireAdmin(supabase: SupabaseClient): Promise<{ id: string; email: string | null } | null>`
   — accepts a session-aware Supabase client (the one from
   `createClient()` in `src/lib/supabase/server.ts`). Calls
   `const { data: { user } } = await supabase.auth.getUser()`. If there is no
   `user`, return `null`. If `isAdminUser(user.id)` is `false`, return `null`.
   Otherwise return `{ id: user.id, email: user.email ?? null }`. This is a
   SESSION-COOKIE check — there is NO bearer token (unlike seed-explore's
   dev-script token gate). Never throws — wrap the `getUser()` call in
   try/catch and return `null` on any error.

Import the `SupabaseClient` type with
`import type { SupabaseClient } from '@supabase/supabase-js'`.

Add a file-level comment: this is the first real admin helper in the codebase;
`profiles` has no `role` column; admin identity is an env allowlist consistent
with the seed-explore env pattern; the gate is fail-safe-closed.

Do NOT import or call `createClient` inside this module — the caller passes the
client in, so the same helper works from both a Server Component and a Route
Handler. Do NOT add a React import.
