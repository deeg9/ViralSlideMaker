# Plan 84-03: Deterministic Extraction + Oracle Proof

## Objective

Land `extractLayoutRecipe` — a PURE deterministic function turning a source
carousel's `Slide[]` (+ optional resolved template style) into a validated
`LayoutRecipe` + a flat style object. NO Gemini call, NO new AI tier
(locked cost constraint). Prove SC4: extraction on an Oracle-pattern
carousel reproduces the Oracle look.

## Context

- **Pure deterministic** — same input → byte-identical output across N
  calls. No I/O, no `Date.now`, no random, no console. Mirror the
  `projectStyleSpecToSlideOverrides` contract in
  `src/lib/ai/style-spec-projector.ts`.
- **Slide → role** (deterministic, no inference): slide index 0 → `cover`;
  any slide with `is_cta === true` → `cta`; all others → `body`. Both
  fields exist on `Slide` (`src/lib/types/slide.ts`).
- **Representative geometry** across N `body` slides: median per numeric
  field, mode per enum field — robust to outliers, deterministic. Median
  of an even-length set = lower-middle element after a stable sort (pick a
  single rule and document it so output is byte-stable). Mode ties broken
  by tuple declaration order.
- **layout_mode classification per role:** derive from each slide's
  `style_overrides`. Heuristic (deterministic):
  - `caption_bar_enabled === true` → `caption-bar-bottom` if
    `caption_bar_position !== 'top'`, else `caption-bar-top`.
  - else if the slide has 2 `custom_images` → `photo-collage-2up`;
    4+ → `photo-collage-grid`.
  - else → `full-bleed-text-overlay`.
  - An unclassifiable slide → `DEFAULT_FALLBACK_ARCHETYPE`
    (`'full-bleed-text-overlay'`).
  Per role, take the MODE of the per-slide classifications.
- **caption_card geometry** populated only when the role's mode is a
  caption-bar archetype: `enabled` true; `x` ← median of
  `caption_bar_x` (default 0); `y` ← median of `caption_bar_y`
  (default 0); `width` ← median of `caption_bar_width` (default 100);
  `height_pct` ← median of `caption_bar_height_pct` (default 38);
  `blend_pct` ← median of `caption_bar_blend_pct` (default 0); `opacity`
  ← median of `caption_bar_opacity` (default 0.85); `position` ← mode of
  `caption_bar_position` (default `'bottom'`).
- **hook placement:** `position_band` ← bucket the median `hook_position.y`
  (or `text_position`) into `HOOK_POSITION_BANDS`
  (0–20 top, 20–40 upper, 40–60 center, 60–80 lower, 80–100 bottom);
  `font_size_band` ← bucket the median `hook_font_size`
  (sm <48, md 48–72, lg 72–110, xl ≥110 — at the 1080×1920 reference);
  `text_align` ← mode of `text_align` (default `'center'`).
- **accent_cadence:** count how many body slides have any accent signal
  (a `TextSegment` with `accent === true` OR a `highlightColor`/
  `highlightStyle` in `hook_segments`/`body_segments`/`text_boxes[].segments`);
  ratio → `ACCENT_CADENCES`: 0 → `none`, ≤1/3 → `sparse`,
  >1/3 to ≤2/3 → `every-other`, >2/3 → `frequent`.
- **accessory_label slot:** `enabled` true for a role iff any slide of
  that role has a non-empty `Slide.accessory_label`; `position_band`
  `'top'` (Phase 82 accessory labels are top-anchored kickers).
- **flat style** is a SEPARATE return value (not part of `LayoutRecipe`).
  Derive it from the most-common per-slide `style_overrides` values
  (`text_color`, `hook_text_color`, `body_text_color`, `background_color`,
  `overlay_color`, `overlay_opacity`, `hook_font_family`,
  `body_font_family`, `treatment_applied`), falling back to the passed
  `template` partial when a field has no per-slide value. Return type is a
  `Partial<SlideStyleOverrides>` — do NOT invent new fields.
- **skip-emit / never-error:** a role with zero matching slides is OMITTED
  from `recipe.roles` (no key emitted). Extraction NEVER throws — an empty
  `slides` array yields `{ recipe: { schema_version:1, accent_cadence:'none',
  roles:{} }, flatStyle:{} }`.
- The final recipe is round-tripped through `parseLayoutRecipeSafe` (Plan
  84-02) before return, so the output is always a validated `LayoutRecipe`.
- **Phase boundary:** this plan does NOT write the recipe into the
  `templates` table (Phase 86) and does NOT apply it at generation time
  (Phase 85).

2. Imports: types `Slide`, `SlideStyleOverrides` from `@/lib/types/slide`;
   `LayoutRecipe`, `RoleLayout`, `RecipeRole`, `HOOK_POSITION_BANDS`,
   `HOOK_FONT_SIZE_BANDS`, `ACCENT_CADENCES`, `LAYOUT_RECIPE_VERSION` from
   `@/lib/types/layout-recipe`; `SlideArchetype`,
   `DEFAULT_FALLBACK_ARCHETYPE` from `@/lib/types/style-spec-archetypes`;
   `parseLayoutRecipeSafe` from `@/lib/validators/layout-recipe`.

3. Pure helpers (each documented, each deterministic):
   - `median(nums: number[]): number | undefined` — stable numeric sort
     ascending; for even length pick the lower-middle element (index
     `Math.floor((n-1)/2)`); empty → `undefined`. Round to 1 decimal.
   - `mode<T>(values: T[], order: readonly T[]): T | undefined` — most
     frequent value; ties broken by earliest index in `order`; empty →
     `undefined`.
   - `classifySlideArchetype(slide: Slide): SlideArchetype` — applies the
     classification heuristic from the Context section above; returns
     `DEFAULT_FALLBACK_ARCHETYPE` when unclassifiable.
   - `bucketHookPositionBand(y: number | undefined)` — maps a y percent
     into `HOOK_POSITION_BANDS` using the boundaries in Context; undefined
     → `'center'`.
   - `bucketHookFontSizeBand(px: number | undefined)` — maps a font-size
     px into `HOOK_FONT_SIZE_BANDS` using the boundaries in Context;
     undefined → `'md'`.
   - `slideHasAccentSignal(slide: Slide): boolean` — true if any segment
     across `hook_segments` / `body_segments` / `text_boxes[].segments`
     has `accent === true` OR a `highlightColor` OR `highlightStyle`.

4. `extractRoleLayout(slidesForRole: Slide[]): RoleLayout | undefined` —
   returns `undefined` when `slidesForRole` is empty (skip-emit). Otherwise:
   - `layout_mode` ← `mode` of `classifySlideArchetype` over the slides
     (order = `SLIDE_ARCHETYPES`), default `DEFAULT_FALLBACK_ARCHETYPE`.
   - `caption_card` ← populated only when `layout_mode` is
     `caption-bar-bottom` or `caption-bar-top`, using the median/mode
     extraction + defaults from Context.
   - `hook` ← `{ position_band, font_size_band, text_align }` from the
     bucket helpers + `text_align` mode (default `'center'`).
   - `accessory_label` ← `{ enabled: true, position_band: 'top' }` iff any
     slide has a non-empty trimmed `accessory_label`; otherwise omitted.

5. `extractAccentCadence(bodySlides: Slide[])` — the ratio rule from
   Context → an `ACCENT_CADENCES` value.

6. `extractFlatStyle(slides: Slide[], template?: Partial<SlideStyleOverrides>)
   : Partial<SlideStyleOverrides>` — for each style field listed in
   Context, take the most-common per-slide value (mode); fall back to
   `template?.<field>` when no slide has a value; OMIT the key entirely
   when neither source has a value (skip-emit). Returns a plain object.

7. Public entry point:
   ```ts
   export interface ExtractLayoutRecipeResult {
     recipe: LayoutRecipe
     flatStyle: Partial<SlideStyleOverrides>
   }

   export function extractLayoutRecipe(
     slides: Slide[],
     template?: Partial<SlideStyleOverrides>,
   ): ExtractLayoutRecipeResult
   ```
   - Partition slides into roles: index 0 → `cover`; `is_cta === true` →
     `cta`; rest → `body`. (A slide at index 0 that is also `is_cta` →
     `cover` wins; index-0 rule takes precedence.)
   - Build `roles` by calling `extractRoleLayout` per non-empty role;
     OMIT roles whose `extractRoleLayout` returns `undefined`.
   - Build the unvalidated recipe: `{ schema_version:
     LAYOUT_RECIPE_VERSION, accent_cadence: extractAccentCadence(bodySlides),
     roles }`.
   - Round-trip through `parseLayoutRecipeSafe`; on `ok:true` return
     `result.recipe`; on the (should-not-happen) `ok:false` path return the
     unvalidated recipe cast to `LayoutRecipe` — extraction never throws.
   - Empty `slides` → `{ recipe: { schema_version: 1, accent_cadence:
     'none', roles: {} }, flatStyle: {} }`.
   - Compute `flatStyle` via `extractFlatStyle`.

8. NO `import` of Gemini SDK, Supabase, or React. NO `Date.now`, `Math.random`,
   `console.*`.
