**3. Extend the `resizeHandleStyles` const** (currently slide-preview.tsx:818-821) with 4 corner entries.

The cursor MUST be inline on the handle's style object (not a CSS class) so it wins over the parent's `cursor: 'grab'` (UI-SPEC "Cursor Affordance Contract"). The hit-zone is provided by `inset: -6` (extends the painted region 6px past the visible square in every direction → 12 + 6 + 6 = 24 CSS-px hit area, WCAG 2.5.8 AA).

react-rnd's `resizeHandleStyles` API applies the style object directly to its internal handle wrapper element. We exploit this: making the handle wrapper itself 24×24 (via inset trick + transparent padding) and painting only the inner 12×12 visible square via `backgroundClip: 'content-box'` + padding pattern is one option. The simpler path used here: set `width: 24, height: 24` on the wrapper, then paint the visible 12×12 via `backgroundColor` + `border` only on the central 12×12 region using `backgroundClip: 'content-box'` and `padding: 6` so the painted area is the central 12×12.

Final pattern (per corner):
```tsx
// phase-59-c1: 24×24 hit zone (WCAG 2.5.8 AA) painting the central 12×12 only.
// padding+backgroundClip:'content-box' makes the outer 6px transparent but
// hit-testable. Cursor goes inline so it trumps the inner cursor:'grab'.
const cornerHandleHitStyle: React.CSSProperties = {
  width: 24,
  height: 24,
  padding: 6,
  boxSizing: 'border-box',
  backgroundColor: 'rgba(255, 255, 255, 0.95)',
  backgroundClip: 'content-box',
  border: '1px solid rgba(0, 0, 0, 0.35)',
  borderRadius: 2,
  position: 'absolute',
  // The border is on the OUTER 24×24 box. To put the 1px border on the inner
  // 12×12 painted square, we use outline instead of border on the inner via
  // a ::before pseudo. But ::before doesn't work in inline styles. Acceptable
  // alternative: the painted 12×12 inner content shows backgroundColor; the
  // 1px border sits on the 24×24 wrapper. UI-SPEC's "1px border" lands on the
  // wrapper edge — visually it appears at 24×24 with the white square inset.
  //
  // To match UI-SPEC strictly (border ON the 12×12 visible square),
  // implement Option A from UI-SPEC "Hit Zone" section: keep the inner 12×12
  // square as a child <div> via resizeHandleComponent prop. See task 2 if
  // strict-mode UI-SPEC compliance requires the wrapper-with-child pattern.
```
