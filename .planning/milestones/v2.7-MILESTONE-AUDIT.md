## Tech Debt Summary

**Satori `display:flex` bug — FIXED INLINE (not deferred)**

The latent `/api/render` crash when serving multi-segment hook slides (error: `Children with multiple elements must use display:flex`) was discovered during Phase 48 thumbnail generation. It was fixed in the same Phase 48 cleanup cycle:

- Commit `e96fd3a` adds `display: 'flex'` + `flexWrap: 'wrap'` to `hookStyle` and `bodyStyle` in `render-slide-satori.tsx`
- Commit `8cad3b4` extends the same fix to `custom_texts` Satori divs
- Satori snapshots updated (4 hook + 4 body style property changes; visual rendering unchanged)
- Thumbnail segment-strip workaround removed; PNGs regenerated with real mint pills

This bug was non-theoretical after Phase 47 landed (`TPLAI-03` explicitly emits multi-segment hooks). Fixing it inline rather than deferring to v2.8 was the correct call — the fix was surgical (two CSS property additions + snapshot update) and required no architectural changes.

**Pre-existing test debt (11 failures, unchanged):** These are pre-v2.7 failures in stripe checkout, sync-subscription, projects CRUD, rate-limit, and slide-canvas position tests. They predate this milestone, are fully documented in `deferred-items.md` files per phase, and were not introduced by any v2.7 work. Recommended: a dedicated test-hygiene quick task before v2.8.
