## Integration

All API routes use the `withApiAuth` HOC chain: auth → rate limit → credit balance → CORS → handler. The service layer (`projects.ts`, `carousel.ts`) is shared between server actions (web UI) and API route handlers. Credit deduction uses the admin client variant (`deductCreditAdmin`) for API routes.
