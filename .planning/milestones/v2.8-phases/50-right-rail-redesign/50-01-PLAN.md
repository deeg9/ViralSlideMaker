### T-01 — Directory + extracted utilities

**Files (NEW):**
- `src/components/editor/text-rail/color-swatches.ts` — extract `colorSwatches` constant from current panel
- `src/lib/editor/text-segments.ts` — extract `splitToSegments` (used by AccentWordsDisclosure and the legacy panel)

```typescript
// color-swatches.ts
export const COLOR_SWATCHES = ['#ffffff', '#3d0000', '#7d6161', '#fadbdb'] as const

// text-segments.ts
import type { TextSegment } from '@/lib/types/slide'
export function splitToSegments(text: string): TextSegment[] {
  const trimmed = text.trim()
  if (!trimmed) return []
  return trimmed.split(/\s+/).map((word) => ({ text: word, accent: false }))
}
```

### T-02 — `LayerStrip` component

**File:** `src/components/editor/text-rail/LayerStrip.tsx` (NEW)

```typescript
interface LayerStripProps {
  textBoxes: TextBox[]
  selectedTextBoxId: string | null
  onSelect: (textBoxId: string) => void
  onAdd: () => void  // dispatches ADD_TEXT_BOX with role='custom'
}
```

Render: horizontal flex row, scroll-x on overflow. Each TextBox = chip showing role icon + first ~16 chars of `text`. Active chip = `bg-[#3d0000] text-white`. Role icons (lucide):
- 'hook' → `Type` (or `Heading`)
- 'body' → `AlignLeft`
- 'custom' → `Square`

Empty text → render "(empty)" placeholder in chip.

Test (`__tests__/LayerStrip.test.tsx`):
- renders one chip per TextBox with role icon + text preview
- active chip has active styling
- click on chip calls onSelect with chip's id
- click on "+ Add" calls onAdd
- handles empty textBoxes array (only "+ Add" chip)

**Acceptance:** Component compiles, tests pass.

### T-05 — `ActiveTextBoxCard` component

**File:** `src/components/editor/text-rail/ActiveTextBoxCard.tsx` (NEW)

Props:
```typescript
interface ActiveTextBoxCardProps {
  textBox: TextBox
  onUpdate: (updates: Partial<TextBox>) => void
  template: SlideTemplate            // for accentColor
  brandKit?: BrandKit | null         // for font picker brand defaults
}
```

Render: bordered card `bg-white border-2 border-[#3d0000]/20 focus-within:border-[#3d0000] rounded-2xl p-5 space-y-4`. Children:

1. **Role label** (top-left, small): role-derived label
   - role='hook' → "HOOK TEXT"
   - role='body' → "BODY TEXT"
   - role='custom' → "TEXT BOX"
2. **Textarea** — `value={textBox.text}`, `onChange` calls `onUpdate({ text: e.target.value, segments: undefined })` (segments cleared on text edit, matching current behavior)
3. **Font row** — `<FontPicker selected={textBox.font_family ?? 'Anton'} onChange={(f) => onUpdate({ font_family: f })} />`
4. **Style row** — Bold/Italic toggle buttons (B/I), wired to `font_weight` (700 vs 400) and `font_style` ('italic' vs 'normal')
5. **AccentWordsDisclosure** — render `<AccentWordsDisclosure segments={textBox.segments ?? splitToSegments(textBox.text)} onToggle={...} accentColor={template.accentColor ?? '#3d0000'} />`. Toggle handler: `onUpdate({ segments: nextSegments })`.
6. **Size slider** — single range input bound to `textBox.font_size`
7. **Color swatches** — row of 4 hard-coded swatches + 1 custom color picker; calls `onUpdate({ color })`
8. **Align row** — left/center/right buttons → `onUpdate({ text_align: 'left' | 'center' | 'right' })`
9. **"Effects" subhead** — small uppercase label
10. **3× EffectRow** — Shadow / Outline / Highlight, each toggling `textBox.effects.{shadow,outline,highlight}.enabled` and revealing inline sliders + color when on. Pull the slider/swatch JSX from current `text-effects-controls.tsx` body.

Test (`__tests__/ActiveTextBoxCard.test.tsx`):
- renders all child sections in order
- typing in textarea calls onUpdate({ text, segments: undefined })
- B button toggles font_weight 400 ↔ 700
- color swatch click calls onUpdate({ color })
- Shadow toggle on reveals shadow controls; toggle off hides them
- 3 effects can all be on simultaneously

**Acceptance:** Component compiles, tests pass.
