# Plan 49-01: Types + Adapter + Adapter Tests

**Phase:** 49 — Schema Unification & Migration
**Plan:** 01 of 02
**Goal:** Define the `TextBox` interface, extend `Slide` with `text_boxes?: TextBox[]`, build the pure `legacyToTextBoxes` / `textBoxesToLegacy` adapter, and prove round-trip parity for 5 representative legacy shapes.

## Scope

This plan ships ONLY type definitions and the adapter module + its unit tests. No reducer changes, no UI changes, no integration with slide-editor.tsx. Plan 49-02 wires the adapter into the reducer + save path.

- **REVISED D-01:** Use `crypto.randomUUID()` for `TextBox.id`, NOT nanoid. Matches the existing pattern at `editor-reducer.ts:88` (`crypto.randomUUID()` for custom_texts) and `editor-reducer.ts:131` (custom_images). Avoids adding a new dependency.
- **REVISED D-16:** `selectedTextBoxId` is **NOT** stored inside `EditorHistory.present` (which is `Slide[]`, a flat array — see `editor-reducer.ts:6-10`). Instead, selection state lives outside the history shape (Plan 49-02 will decide the exact home: either as `EditorHistory.selectedTextBoxId: string | null` alongside past/present/future, or as separate React state in `slide-editor.tsx`). Selection changes must NOT push history (D-15 unchanged).

```typescript
  text: string
  segments?: TextSegment[]

  font_size?: number            // px in 1080x1920 reference
  font_weight?: number
  font_style?: 'normal' | 'italic'
  color?: string
  text_align?: 'left' | 'center' | 'right'
  effects?: TextEffects
  position: TextBoxPosition
}
```

### T-02 — Adapter module

**File:** `src/lib/editor/text-box-adapter.ts` (NEW)
**Action:** Write

Pure functions, no React/state coupling. Two exports:

1. `legacyToTextBoxes(slide: Slide): TextBox[]` — derives a `TextBox[]` from the legacy fields. Order:
   - Index 0: hook (role='hook'). Maps `hook_text` → `text`, `hook_segments` → `segments`, `style_overrides.hook_*` → font/color/effects, `style_overrides.text_position` → position.anchor (default 'top'), `style_overrides.hook_position` → position.{x,y} when text_position='custom', `style_overrides.hook_width` → position.width.
   - Index 1: body (role='body'). Same mapping for body_text/body_segments/body_*. Position default 'bottom'.
   - Index 2+: each `custom_text` becomes a TextBox with role='custom'. position.anchor='custom', position.{x,y,width} from CustomText.{x,y,width}. Map font_family/font_size/font_weight/font_style/color/text_align/text_effects/segments straight across.
   - Each TextBox gets a `crypto.randomUUID()` id at derivation time.

2. `textBoxesToLegacy(boxes: TextBox[]): { hook_text, body_text, hook_segments?, body_segments?, custom_texts?, style_overrides_patch }` — inverse function. Returns:
   - `hook_text` from boxes[role='hook'].text (or '' if missing)
   - `body_text` from boxes[role='body'].text (or '' if missing)
   - `hook_segments` / `body_segments` from those boxes' segments (when set)
   - `custom_texts` from boxes[role='custom'] mapping back to `CustomText` shape
   - `style_overrides_patch`: a partial SlideStyleOverrides containing hook_*/body_* fields derived from the hook and body TextBoxes (font, size, color, position, effects). Caller deep-merges into existing style_overrides.

Edge cases:
- If hook TextBox is missing, `hook_text = ''` and no hook_segments emitted.
- If body TextBox is missing, `body_text = ''` and no body_segments emitted.
- TextBoxes are emitted in array order, regardless of role mismatches.
- `null`/`undefined` fields on TextBox produce `undefined` on the legacy side (no defaults injected).

**Acceptance:** Module exports both functions; `npx tsc --noEmit` clean.

Round-trip assertion pattern:
```typescript
const original: Slide = { /* shape N fixture */ }

const { hook_text, body_text, hook_segments, body_segments, custom_texts, style_overrides_patch } = textBoxesToLegacy(boxes)
const reconstructed: Slide = {
  ...original,
  hook_text, body_text, hook_segments, body_segments, custom_texts,
  style_overrides: { ...original.style_overrides, ...style_overrides_patch },
}
// Strip TextBox ids from comparison
expect(stripIds(reconstructed)).toEqual(stripIds(original))
```
