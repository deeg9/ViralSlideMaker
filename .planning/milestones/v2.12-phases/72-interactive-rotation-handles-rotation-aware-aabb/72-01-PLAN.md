Rotation-aware AABB math (cos/sin around element center):
```typescript
// For decoration at {x, y, width, height} (% units) with rotation θ degrees:
// 1. Compute center: cx = x + width/2; cy = y + height/2
// 2. Compute 4 corners relative to top-left: (x, y), (x+w, y), (x+w, y+h), (x, y+h)
// 3. Rotate each corner around (cx, cy):
//    nx = cx + (px - cx) * cos(θ_rad) - (py - cy) * sin(θ_rad)
//    ny = cy + (px - cx) * sin(θ_rad) + (py - cy) * cos(θ_rad)
// 4. AABB = { x: min(nx_i), y: min(ny_i), width: max(nx_i) - min(nx_i), height: max(ny_i) - min(ny_i) }
// 5. θ_rad = θ * Math.PI / 180
```
