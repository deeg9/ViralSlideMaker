<objective>
Lift Gemini's slide-generation responseSchema to natively emit `decorations[]` per slide, with strict closed-enum AI-emit shape (DecorationEmitSchema) that NEVER accepts raw hex or raw % coords. Build server-side token resolvers that translate AI's named color tokens + semantic position anchors into explicit hex + safe-zone % coords. Wire the ingest adapter at the post-Zod-parse boundary in generate-slides.ts to resolve + validate + clamp + silent-drop — mirror v2.9 `template_id_override` defaulting pattern + v2.11 `legacyToTextBoxes` adapter pattern.

Purpose: AI-01..04 are the four AI-side wires that make Phase 70's shipped editor surfaces consume Gemini-emitted decorations. The "named tokens, never raw hex" + "semantic anchors, never raw coords" constraint means AI cannot smuggle template-clashing colors or hook-occluding positions into the carousel — server-side resolution is the firewall. Closed-enum lucideName allowlist (~100 PascalCase, subset of Phase 69's 118) prevents AI hallucinating Phosphor/Heroicons/etc names that would silently render blank. maxItems=2 has dual protection: Gemini schema soft-caps + server-side clamp hard-caps, per AI-02.

- DecorationEmitSchema in schemas.ts (subset of DecorationSchema; closed enums for kind/lucideName/shapeKind/color/position; rotation? optional)

- AI_COLOR_TOKENS + AI_POSITION_ANCHORS enums (6 tokens + 7 anchors per CONTEXT.md decision)

- generate-slides.ts: responseSchema extended with slides[].decorations field; post-parse ingest adapter resolves + validates + clamps + silent-drops
- ~25 unit tests across 3 test files

```typescript
// Hex regex used by every Decoration color field
const HexColorSchema = z.string().regex(/^#[0-9A-Fa-f]{6}([0-9A-Fa-f]{2})?$/)

export const DecorationPositionSchema = z.object({
  x: z.number(),
  y: z.number(),
  width: z.number(),
  height: z.number(),
})

const DecorationBaseFields = {
  id: z.string(),
  position: DecorationPositionSchema,
  groupId: z.string().optional(),
  locked: z.boolean().optional(),
  hidden: z.boolean().optional(),
  name: z.string().optional(),
  rotation: z.number().optional(),
  opacity: z.number().min(0).max(1).optional(),
  effects: DecorationEffectsSchema.optional(),
} as const

export const IconDecorationSchema = z.object({
  kind: z.literal('icon'),
  ...DecorationBaseFields,
  lucideName: z.string().min(1),
  color: HexColorSchema,
  strokeWidth: z.number(),
})

export const ShapeDecorationSchema = z.object({
  kind: z.literal('shape'),
  ...DecorationBaseFields,
  shapeKind: z.enum(['rect','circle','ellipse','triangle','polygon','star','arrow','line']),
  fill: HexColorSchema,
  stroke: DecorationStrokeSchema.optional(),
  cornerRadius: z.number().optional(),
  points: z.number().optional(),
})

export const DecorationSchema = z.discriminatedUnion('kind', [IconDecorationSchema, ShapeDecorationSchema])
export function parseDecorationsArraySafe(input: unknown): DecorationContent[]  // silent-drop array parser
export type DecorationContent = z.infer<typeof DecorationSchema>
```
