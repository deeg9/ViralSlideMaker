# Milestone v2.9: Viral Visual Quality

**Status:** SHIPPED 2026-05-01
**Phases:** 54-58
**Total Plans:** 11

## Overview

Upgrade the visual output of AI-generated carousel slides so they look like what's actually winning on TikTok and Instagram in early-to-mid 2026 — replicating proven patterns from successful creators (editorial / Notes-App-Chic / Brutalist) rather than guessing.

Research-grounded in Aesthetics of Photography "Viral Visual Grammar of US Instagram in 2026", Canva *Imperfect by Design 2026*, It's Nice That graphic trends 2026, Mosseri Jan 2026 "rawness is proof," verified Satori issues #573 / #162 / #712, Imagen 4 Fast pricing, 9th Cir. right-of-publicity precedent (Reface/Kyland Young).

**Success metric:** ZIP download rate per created carousel — proxy for "good enough to ship." Baseline captured at Phase 54 start (`v2.9-METRIC-BASELINE.md`); ship-gate non-regression verified at Phase 58.

**Build-order dependency (locked, no parallelization):** 54 → 55 → 56 → 57 → 58.

**Parity invariant (TPLREND-05):** every new visual layer MUST be exported from `src/lib/render/resolve-overlay.ts` and consumed by both `render-slide-satori.tsx` and `slide-preview.tsx`. Preserved end-to-end across all 11 templates.

## Phases

### Phase 54: Infrastructure Foundation

**Goal**: Server-side photo-treatment pipeline + Imagen 4 Fast + AI-slop guardrails + success-metric baseline are live; nothing user-visible has changed yet, but every downstream phase builds on this foundation
**Depends on**: Phase 53
**Requirements**: TREAT-01..06, SLOP-01, SLOP-02, SLOP-04, SLOP-05, METRIC-01..03 (13 reqs)
**Plans**: 2 plans

Plans:
- [x] 54-01-PLAN.md — Treatment foundation: sharp install + sharp-config + treat.ts (4 presets, SHA-256 cache) + pure unit tests + slide-backgrounds-treated bucket migration + 7-day retention pg_cron *(Wave 1)*
- [x] 54-02-PLAN.md — Guardrails + metric: slop-guardrails.ts module + 4 call-site integrations (Imagen/Pexels/AI hook) + Inter→Plus Jakarta Sans swap on magazine-bold/documentary + Imagen 4 Fast verification audit + carousel_events extension + v_zip_download_rate view + track-download endpoint + capture-zip-baseline script *(Wave 2, depends on 54-01)*

**Details:**
- `treatPhoto(sourceUrl, spec)` returns treated PNG URL + extracted palette; idempotent via SHA-256 cache key of `(sourceUrl + spec)`. Presets: `bw`, `duotone-cream`, `duotone-cobalt`, `contrast-bump`.
- `sharp.cache(false)` and `sharp.concurrency(1)` set at module load to prevent serverless memory fragmentation.
- New public Supabase Storage bucket `slide-backgrounds-treated` with 7-day retention via `pg_cron`.
- Imagen 4 Fast (`imagen-4.0-fast-generate-001`) replaces Imagen 3 ($0.04 → $0.02/img, 10× faster, better text rendering).
- Imagen prompt addendum forbids gradient backgrounds / glossy 3D / abstract blobs.
- Pexels query helper appends "natural lighting, candid, editorial, portrait" and excludes `meeting, office, team, smiling, diverse group`.
- AI hook system-prompt forbids "In a world where" / "Did you know" / "Imagine if" openings.
- Premium templates audited: `magazine-bold` and `documentary` flipped Inter → Plus Jakarta Sans `bodyFontFamily`.
- `download_zip` event tracked per project download (event_type CHECK constraint allowlists 'view' + 'download_zip').
- `v_zip_download_rate` view live (53 projects, 0% baseline since download tracking is brand-new).
- Baseline captured to `.planning/milestones/v2.9-METRIC-BASELINE.md`.

**Depends on**: Phase 54
**Requirements**: TYPO-01..05, SLOP-03 (6 reqs)
**Plans**: 2 plans

Plans:
- [x] 55-01-PLAN.md — Schema additions + types + SLOP-03 validator
- [x] 55-02-PLAN.md — `renderGrain` + `renderVignette` resolver helpers + parity wiring

**Details:**
- `SlideTemplate` extended with optional `grainMode`, `vignette`, `photoTreatment`, `paletteMode`, `coverLayout`, `bodyFontFamily` (required on premium templates by validator).
- `Slide` extended with optional `original_source_url`, `style_overrides.derived_palette: string[]`, `style_overrides.treatment_applied: string`, `template_id_override?: string`.
- `renderGrain(intensity)` and `renderVignette(strength)` exported from `src/lib/render/resolve-overlay.ts`; both renderers import from the same module — TPLREND-05 invariant preserved.
- CSS filter properties NOT used in any new render layer — server-side sharp pre-bake from Phase 54 is the only path.
- Font catalog adds 4 static-TTF entries: Archivo Black, Space Grotesk, Manrope, DM Serif Display via Fontsource. No variable fonts (Satori issues #162/#712 unresolved). No Pangram fonts ($120 deferred).
- Premium template hook `fontSize` raised from 88px to per-template 110-130px range.
- `validateTemplateRegistry` extended to require `bodyFontFamily` on every premium-tier template.
- Legacy 8 templates unchanged (additive optional fields only); v2.7's 19/19 requirements re-verified — zero regression.

- [x] 56-03-PLAN.md — Three new free-tier templates + parity tests
- [x] 56-04-PLAN.md — Picker DOM regression test extended for 3 new templates

**Details:**
- `editorial-serif` template (NYT/SSENSE aesthetic): B&W bleed photo (auto-treated via TREAT preset `bw`), Playfair Display 130px hook, cream `#F5EFE6` accent, page counter top-right, medium grain overlay.
- `notes-app-chic` template (Loewe/Duolingo aesthetic): paper-texture background, ransom-note hook (mixed fonts via per-segment `fontFamily`), tape-strip + sticky-note + halftone-dot overlay assets, photocopier-grain overlay.
- `brutalist-grid` template (AIGA/Eye on Design aesthetic): hard 8-column grid, type-as-image hero (oversized hook fills frame), high-contrast B&W with single accent color, no decorative overlays.
- 14 decorative SVG/PNG assets in `public/overlays/` (tape strips ×3, sticky notes ×3 colors, halftone dot patterns ×2 densities, hand-drawn arrows ×4 directions, polaroid frame, paper torn-edge).
- 5 grain PNGs in `public/textures/`: `grain-subtle.png`, `grain-medium.png`, `grain-heavy.png`, `paper-texture.png`, `xerox-grain.png` — all 1080×1920 tileable, generated via committed `scripts/build-textures.ts` (`npm run textures`).

- Per-template `coverLayout` distinct from `innerLayout`.
- `npm run thumbs` extended for the 3 new templates (8 → 11 PNGs); `/templates` picker DOM regression test asserts thumbnails resolve.
- Each new template passes parity audit — same `(slide_data, template_id)` produces byte-identical output between `<SlidePreview>` and Satori PNG export.

### Phase 57: Editor Controls + Palette Extraction

**Goal**: Users can override photo treatment per slide from the right rail; palette-aware templates auto-derive accent colors from background photos; the canvas editor shows an Instagram-grid safe-zone overlay so users can see what the 3:4 grid crop will hide
**Depends on**: Phase 56
**Requirements**: EDITOR-01..04, PALETTE-01..04 (8 reqs)
**Plans**: 3 plans

Plans:
- [x] 57-01-PLAN.md — node-vibrant + extractPalette + grain_intensity + 5 resolver helpers
- [x] 57-02-PLAN.md — Editor UI: photo-treatment-controls + IG grid + updateSlideTreatment
- [x] 57-03-PLAN.md — paletteMode flip + generation pipeline + retention audit

**Details:**
- New `src/components/editor/photo-treatment-controls.tsx` mounts in the right rail below `SlideSettings` (no v2.8 layout regression); offers per-slide B&W toggle, duotone preset picker (cream / cobalt), grain intensity (off / subtle / medium / heavy).
- Wired to `editor-actions.ts: updateSlideTreatment(slideIndex, spec)` server action.
- Treatment toggle always re-treats from `slide.original_source_url` (never compounds on already-treated output); cache hit on second toggle is instant.
- `node-vibrant@4.0.4` installed (server-only, `'use server'` boundary); `extractPalette(treatedUrl)` returns named roles `{ Vibrant, DarkVibrant, LightVibrant, Muted, DarkMuted, LightMuted }` as hex strings.
- Runs on a sharp-resized ≤256×256 thumbnail (Vercel function memory budget).
- `slide.style_overrides.derived_palette` populated at generation time and on every editor treatment override.
- `editorial-serif` and `notes-app-chic` flipped to `paletteMode: 'palette-dominant'` and consume `derived_palette` (Vibrant for chip backgrounds, DarkMuted for text on light backgrounds).
- Instagram grid safe-zone overlay rendered in canvas editor when "IG grid preview" toggle is on: 4:5 (1080×1350) crop bounds shown as dashed outline — CSS-only, no rendering changes.

- [x] 58-02-PLAN.md — Premium-gated match-photos with cache + 10s timeout + credit ledger

**Details:**

**Stats:**
- 5 phases (54-58) · 11 plans · ~30 commits between `04780ae` (roadmap) and `5c58cfd` (final ship-gate)

- Photo treatment baked server-side via sharp — CSS filters silently break Satori PNG export (vercel/satori#573); pre-render is the only path.

- All 3 new templates free for all users — pre-PMF, top-of-funnel sharing > premium gating.
- `match-photos-to-slides.ts` ships in Phase 58 premium-gated only (cost mitigated by `MAX_PHOTOS=8` + cache + timeout).
- Success metric = ZIP download rate. Baseline measured at Phase 54 start; ship gate at Phase 58 verifies non-regression.
- 5 phases (54-58) chosen over 7 (Architecture proposed) — phases group by build-order dependency.
