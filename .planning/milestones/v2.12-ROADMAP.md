## Decisions

| Decision | Rationale |
|----------|-----------|
| lucide-react v1.14 upgrade yielded negative bundle delta | Tree-shaking improvements in v1; -169 bytes gz on editor route; justifies upgrade before feature work |
| `lucide-static` for Satori SVG strings | Satori cannot dynamically import React components; pre-resolved SVG strings are the only byte-identity-safe path |
| Pre-baked SVG assets in `public/shapes/` via `scripts/build-shapes.ts` | Inline `<svg>` JSX unsupported by Satori (`presets.ts` shape list); pre-baked = same asset in both renderers = TPLREND-05 preserved |
| Advisory monoculture gate (does NOT fail CI in v2.12) | Mirror v2.9 `hookOpeningTrigram` pattern; promote to fail-CI + retry-once in v3.0+ if production data shows monoculture |
| CSS `box-shadow` for shadow effects (never SVG `<filter>`) | vercel/satori#573 silently drops `filter:` / `backdrop-filter:` (burned in v2.9); CSS box-shadow confirmed supported |
| `isPickerOpenRef` firewall on all 33 tinykeys sites | Picker keyboard scope must suspend editor scope; Cmd+G must NOT fire GROUP while picker is open |
| `BULK_ROTATE` routes decorations only in v2.12 | text_boxes/custom_images/watermark rotation deferred as documented no-op stubs; clean extension surface for v2.13+ |
