## End-to-end flow check

### Flow 1: Free-tier user generation
1. User submits prompt → AI generates slides with role + (optional) template_id_override.
2. Pexels search applies SLOP-02 query/exclusion guardrails.
3. For templates with `photoTreatment`, `treatPhoto` runs server-side; sharp B&W/duotone/grain bake; deterministic SHA-256 cache.
4. For `palette-dominant` templates, `extractPalette` populates `derived_palette` from treated thumbnail.
5. `original_source_url` preserved on every slide.
6. PNG export via Satori — no CSS filter properties anywhere; metadata clean (no EXIF/XMP/C2PA).

**Status:** PASS. All five steps wired and tested.

### Flow 2: Premium-tier user with photo upload
1. User uploads photos → `matchPhotosToSlides` invoked (premium gate active).
2. Cache lookup by `(photoSetSHA256, slideManifestSHA256)`.
3. Cache miss → Gemini Vision call with 10s `Promise.race` timeout; `gemini_vision_match` credit charged.
4. Timeout/error/zero-assignments → refund credit + fall through to index-order.
5. `MAX_PHOTOS=8` ceiling protects per-call cost.

**Status:** PASS.

### Flow 3: Editor treatment override
1. User opens canvas editor → IG-grid safe-zone overlay available (CSS-only chip toggle).
2. Right-rail `photo-treatment-controls` mounted below `SlideSettings`.
3. User toggles B&W/duotone/grain → `updateSlideTreatment` server action fires.
4. Step 1 back-fills `original_source_url` if null.
5. Step 2 'none' branch resets `background_url ← original_source_url`; otherwise step 3 calls `treatPhoto` + `extractPalette`; `derived_palette` re-written.
6. No compounding (always re-treats from original).

**Status:** PASS. `text-editor-panel-composition.test.tsx` snapshot pins right-rail order.

### Flow 4: ZIP download success-metric loop
1. User clicks ZIP download → `downloadSlidesAsZip` fires keepalive POST to `/api/v1/projects/[id]/track-download`.
2. `download_zip` event inserts into `carousel_events` (CHECK constraint allowlists 'view' + 'download_zip').
3. `v_zip_download_rate` view returns 5-col tuple for any time window.
4. Baseline captured (`v2.9-METRIC-BASELINE.md`); ship-gate verifies non-regression.

**Status:** PASS. Ship-gate items 10 + 14 + 15 all green.

**Flow findings: 4/4 flows complete end-to-end. No breaks.**
