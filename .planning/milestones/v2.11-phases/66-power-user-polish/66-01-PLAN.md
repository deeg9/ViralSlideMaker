Reference unit conversion (used to convert ±1 / ±10 reference px to % of canvas):
- REF_WIDTH = 1080
- REF_HEIGHT = 1920
- 1 ref-px in % of width  = 100 / 1080 ≈ 0.09259...
- 10 ref-px in % of width = 100 / 108     ≈ 0.92593...
- 1 ref-px in % of height = 100 / 1920 ≈ 0.05208...
- 10 ref-px in % of height = 100 / 192    ≈ 0.52083...
- Default duplicate offset (~20 ref-px each axis):
  - 20 / 1080 * 100 ≈ 1.8519
