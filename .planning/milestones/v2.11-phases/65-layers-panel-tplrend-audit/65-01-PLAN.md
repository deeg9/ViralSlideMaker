<objective>
Mount a NEW LEFT-rail layers panel beneath the slide-list strip, rendering a vanilla flat list of every element on the current slide (text_boxes ∪ custom_images ∪ watermark) plus synthesized group-collapse rows. Click selects, Shift-click toggles, double-click opens an `<input>` for inline rename. Selection state is read-only in the panel — both panel and canvas dispatch through the existing `useSelectionModel`; no infinite-loop sync. Each `LayerChip` is wrapped in `React.memo` with custom equality so selection changes touch O(2) chips, not O(N).
