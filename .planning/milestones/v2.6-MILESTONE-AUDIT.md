## Build-Gate Regression Check (the v2.3 retirement cause)

The exact failure mode that retired v2.3 — `mcp-handler` listed in package.json but missing from node_modules → /api/mcp returns 500 — is now blocked by THREE independent layers:

1. **Static (non-type) import** in `src/app/api/[transport]/route.ts` makes Next.js `npm run build` fail at module-resolution time
2. **Vitest import-gate test** at `src/__tests__/mcp/import-gate.test.ts` asserts `typeof createMcpHandler === 'function'`
3. **Phase 42 verify.sh harness** check 8 explicitly asserts mcp-remote dep version pin

Triple coverage. The v2.3 failure cannot recur silently.
