# v2.10 Requirements (Archived) — Text Box Resize Handles

**13/13 active requirements satisfied at code level.** 1 deferred verification gate (A11Y-01 iPhone Safari touch QA — desktop side fully verified, real-device touch testing skipped per orchestrator decision).

## Active Requirements (all complete)

### Resize Handles (RESIZE)

- [x] **RESIZE-01**: User can grab any of 4 corner handles (TL, TR, BL, BR) on a text box (hook, body, or custom) and drag to resize it.
- [x] **RESIZE-02**: Existing left + right side handles remain functional — drag adjusts width only, font size unchanged.
- [x] **RESIZE-03**: Top + bottom handles are explicitly disabled.
- [x] **RESIZE-04**: While holding `Shift` during corner-drag, font size does NOT change — corner becomes width-only escape hatch.

### Font-Scale on Corner-Drag (FONTSCALE)

- [x] **FONTSCALE-01**: Corner-drag scales `font_size` proportionally to the width change in the same drag stroke.
- [x] **FONTSCALE-02**: Past-the-cap = box continues to grow, font caps at role bound (240 hook / 120 body).
- [x] **FONTSCALE-03**: Right-rail font-size slider reflects new value within one render frame after `onResizeStop`.
- [x] **FONTSCALE-04**: Manual `font_size` set via corner-drag overrides the `hook-fit.ts` auto-shrink registry.

### Renderer Parity (PARITY)

- [x] **PARITY-01**: Slide with corner-dragged values renders byte-identical across `slide-preview.tsx` (non-editable), `render-slide.ts`, `render-slide-satori.tsx`.
- [x] **PARITY-02**: Resize handles never leak into Satori PNG export. Editor-only via `editable={true}` gate.

### Undo / History (UNDO)

- [x] **UNDO-01**: Single corner-drag or side-drag gesture produces exactly one undo entry. Dispatch on `onResizeStop` only.

### Touch Accessibility (A11Y)

- [x] **A11Y-01**: All resize handles meet WCAG 2.5.8 AA — 24×24 CSS px hit zone (visual 12×12). Desktop side fully verified; **iPhone Safari real-device tap test deferred** (logged in tech debt).
- [x] **A11Y-02**: Cursor changes to `nwse-resize` (TL/BR) / `nesw-resize` (TR/BL) on corner hover.
