# Requirements: ViralSlideMaker — v2.1 Text Effects (Archived)

**Defined:** 2026-04-07
**Completed:** 2026-04-07
**Core Value:** Type a topic, get ready-to-post carousel slide images -- fully AI-generated, editable, downloadable.

## v2.1 Requirements (All Complete)

### Text Effects Data Model

- [x] **FX-01**: User's text effect settings (shadow, outline, highlight) persist across save/load
- [x] **FX-02**: Each text element (hook, body, custom text boxes) has independent effect settings

### Text Shadow

- [x] **SHAD-01**: User can toggle text shadow on/off for any text element
- [x] **SHAD-02**: User can pick shadow color via swatches and custom color picker
- [x] **SHAD-03**: User can select shadow size from S/M/L presets

### Text Outline

- [x] **OUT-01**: User can toggle text outline on/off for any text element
- [x] **OUT-02**: User can pick outline color via swatches and custom color picker
- [x] **OUT-03**: User can adjust outline thickness via slider (1-8px)

### Background Highlight

- [x] **HL-01**: User can toggle background highlight on/off for any text element
- [x] **HL-02**: User can pick highlight color via swatches and custom color picker
- [x] **HL-03**: User can choose between tight (marker) and full-width (banner) highlight styles
- [x] **HL-04**: User can adjust highlight padding via slider (4-24px)

### Rendering

- [x] **REND-01**: Text effects render correctly in the editor preview (real CSS)
- [x] **REND-02**: Text effects render correctly in Satori PNG export (native textShadow/WebkitTextStroke)
- [x] **REND-03**: Text effects render correctly in HTML export
- [x] **REND-04**: Tight highlight gracefully falls back to full-width in Satori export if needed

### Validation

- [x] **VAL-01**: Validation spike confirms native Satori support for textShadow and WebkitTextStroke before full implementation
