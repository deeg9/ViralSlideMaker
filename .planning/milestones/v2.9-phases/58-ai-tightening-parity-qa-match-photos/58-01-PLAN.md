# Phase 58 Plan 01 — AI Tightening: Slide Roles + Per-Role Prompt + Diversity Corpus

## Goal

Land the AI-tightening requirements (AIROLE-01..05) in a single atomic
plan. Gemini's response schema gains `role` (closed 5-value enum) and
optional `template_id_override` (closed enum from registry). The system
prompt gains per-role copy guidance verbatim. The validator silently
defaults missing/invalid `role` to a deterministic distribution
(`assignSlideRoles`) and silently strips invalid override values —
preserving the never-throws contract from Phase 47.

A 20-prompt diversity corpus lands at `src/lib/ai/__tests__/diversity-corpus.ts`
BEFORE the gate test is written (D-13 ordering). The gate test is
ADVISORY in v2.9 — logs warning, does not fail CI (orchestrator
constraint).

This plan is the foundation. Plan 02 wires the premium-gated
match-photos flow; Plan 03 wires the parity QA + cascade-delete + ship
gate.

## Requirements

- **AIROLE-01**: Gemini response schema extends each slide with
  `role: 'cover' | 'reframe' | 'support' | 'pivot' | 'close'` (first =
  cover, last = close, middle by length).
- **AIROLE-02**: Per-role copy guidance verbatim (cover = pattern-
  interrupt ≤8 words; reframe = "wait, but" tension; support =
  concrete evidence; pivot = unexpected angle; close = action / CTA /
  bookmark prompt).
- **AIROLE-03**: `template_id_override?: string` (closed enum from
  registry) added to response schema; AI may pick a different template
  per slide for visual rhythm; null = use project template.
- **AIROLE-04**: Server-side validator: missing/invalid `role` →
  default to legacy flat distribution; never throws.
- **AIROLE-05**: Existing premium-tier guardrails (length caps, typo
  gate, voice notes) preserved; v2.7 audit baseline (19/19) re-verified
  after prompt change.

Plus:
- **Diversity gate corpus** (D-13): 20-prompt fixture lands BEFORE
  the test that consumes it.

### Task 1 — `assignSlideRoles` helper + tests

Create `src/lib/ai/role-distribution.ts`:

```typescript
// Phase 58 (AIROLE-01, D-05): deterministic role distribution by carousel length.
// Pure function — no I/O, no Gemini, no randomness. Easily unit-testable.

export type SlideRole = 'cover' | 'reframe' | 'support' | 'pivot' | 'close'

const ROLE_TABLE: Record<number, SlideRole[]> = {
  3: ['cover', 'support', 'close'],
  4: ['cover', 'reframe', 'support', 'close'],
  5: ['cover', 'reframe', 'support', 'pivot', 'close'],
  6: ['cover', 'reframe', 'support', 'support', 'pivot', 'close'],
  7: ['cover', 'reframe', 'support', 'support', 'pivot', 'support', 'close'],
  8: ['cover', 'reframe', 'support', 'support', 'pivot', 'support', 'support', 'close'],
  9: ['cover', 'reframe', 'support', 'support', 'pivot', 'support', 'support', 'pivot', 'close'],
  10: ['cover', 'reframe', 'support', 'support', 'support', 'pivot', 'support', 'support', 'pivot', 'close'],
}

/**
 * Phase 58 (AIROLE-01, D-05). Returns a deterministic role array
 * for a carousel of length n. clampedCount in generateCarousel is
 * already capped at 10 — no defaults needed beyond [3, 10].
 *
 * For out-of-range n (defensive — should never happen post-clamp):
 * fall back to ['cover', ...n-2 'support', 'close'].
 */
export function assignSlideRoles(n: number): SlideRole[] {
  if (n in ROLE_TABLE) return [...ROLE_TABLE[n]]
  if (n < 3) {
    // Defensive — clampedCount enforces min 3 in actions.ts already.
    if (n <= 0) return []
    if (n === 1) return ['cover']
    return ['cover', 'close']
  }
  // n > 10 — defensive fallback.
  return ['cover', ...Array(n - 2).fill('support' as const), 'close']
}

export const SLIDE_ROLES: readonly SlideRole[] = [
  'cover',
  'reframe',
  'support',
  'pivot',
  'close',
] as const
```

```typescript
// Phase 58 (AIROLE-04, D-06, D-08): silently default missing/invalid
// role values to the deterministic per-length distribution.
// Silently strip invalid template_id_override values not in registry.
// NO warnings emitted — these are AI emit defaults, not detectable
// mistakes. Never-throws contract preserved.
const defaultRoles = assignSlideRoles(data.slides.length)
data.slides.forEach((slide, idx) => {
  const slideAny = slide as { role?: string; template_id_override?: string }
  if (!slideAny.role || !SLIDE_ROLES.includes(slideAny.role as never)) {
    slideAny.role = defaultRoles[idx]
  }
  if (slideAny.template_id_override !== undefined &&
      !TEMPLATE_IDS.includes(slideAny.template_id_override)) {
    delete slideAny.template_id_override
  }
})
```
