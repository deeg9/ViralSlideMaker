<objective>
Add two new user-facing controls to the Caption Card panel in the carousel editor:

1. **Height slider** — lets the user make the colored caption card taller/shorter. The
   underlying `caption_bar_height_pct` field already exists (resolver clamps 10..90,
   default 38) and is already drawn by all three render paths — it is only settable
   today by dragging the card's resize handles on the canvas. This plan surfaces it as
   a panel slider.
2. **Edge blend toggle + amount slider** — a NEW `caption_bar_blend_pct` field that
   fades the card edge that touches the photo (top edge when snapped Bottom, bottom edge
   when snapped Top) from the card color into transparent via a CSS `linear-gradient`,
   instead of the current hard straight cut.

Purpose: Give users breathing room around captions (height) and a seamless card→photo
transition (blend) — both visible in the editor preview and the exported image.

Output: New `caption_bar_blend_pct` field, a shared `captionCardBackgroundStyle` resolver
helper, both controls wired into all three render paths, and two new panel controls
styled consistently with the existing Color/Opacity controls.
</objective>
