## How text_boxes get their y values (the load-bearing read path)

```typescript
function hookPosition(slide: Slide): TextBoxPosition {
  const overrides = slide.style_overrides
  if (overrides?.hook_position) {
    return {
      anchor: 'custom',
      x: overrides.hook_position.x,
      y: overrides.hook_position.y,
      ...(overrides.hook_width !== undefined ? { width: overrides.hook_width } : {}),
    }
  }
  const anchor = overrides?.text_position ?? 'top'
  return { anchor, ... }
}
```
Same shape for `bodyPosition` (lines 48-64). KEY INSIGHT: if the projector emits `hook_position` into style_overrides, the adapter will produce `anchor: 'custom'` with the projector's x/y/width — exactly what we want, and `separateOverlappingTextBoxes` will see participating boxes in the layout pass.
