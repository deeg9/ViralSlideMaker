# v2.12 Decoration Primitives — Live Smoke Tests via Playwright

## Goal

Take the v2.12 decoration features through real-browser smoke tests (the 6 manual QA items left from milestone close-out plus a few extras). All v2.12 code was machine-generated by 19 plans across 6 phases — find what actually breaks under user input.

## Tests

1. **Boot + load** — dev server boots clean; editor route renders without console errors
2. **Shape picker (`S` key)** — popover opens; 8 shapes render; click circle inserts at slide center
3. **Direct-insert R/C/L** — pressing `R` / `C` / `L` while editor focused inserts rect/circle/line
4. **Lucide picker (`I` key)** — modal opens; ~118 icons load via virtualized grid; fuzzy search "heart" filters to relevant matches; arrow keys traverse; Enter inserts; Esc closes
5. **DecorationCard** — selecting decoration shows right-rail card with fill/stroke/size/shadow/opacity controls; edits round-trip into canvas
6. **Layers panel chip** — decoration appears as chip; lock/hide/z-order toggles work
7. **Rotation handle** — 16px circle above selected decoration; drag rotates; Shift snaps to 15°; Esc cancels
8. **Picker keyboard firewall** — with picker open, Cmd+G must NOT fire GROUP
9. **Open existing v2.11 project** — byte-identity sanity check (decorations === undefined → no visible diff)

## Approach

Use Playwright MCP. Capture findings as we go (each test = pass / fail / observation). Document in SUMMARY.md. Atomic commit at end.
