# Phase quick-260515-k54 Plan 01: Add Resize Handles and Centering Guides to Icons and Shapes Summary

Icons and shapes on the slide-editor canvas are now first-class editable elements: an 8-handle resize box (4 corner + 4 mid-side, icons aspect-locked / shapes free) plus centering-guide snap-on-drag, both wired through the SAME shared machinery text boxes and custom images already use — zero new algorithms, zero new reducer actions.

## What Was Built

**Task 1 — Decorations as snap targets.** Added a `slide.decorations` loop to `buildSnapIndex` directly after the custom-images loop. Each decoration contributes left/center/right X-edges + top/center-v/bottom Y-edges keyed to its id; `excludeIds` suppresses a dragged decoration's edges. Decorations always carry real width/height (no height-0 degenerate case unlike text boxes). Used `(slide.decorations ?? [])` per the TPLREND-05 idempotent-absence constraint.

**Task 2 — `onDecorationSizeChange` prop chain.** Added the optional `onDecorationSizeChange?: (id, {width, height}) => void` prop to `SlidePreview` and `SlideCanvas`, forwarded it through `SlideCanvas`, and added the `slide-editor.tsx` handler that finds the matching decoration and dispatches `UPDATE_DECORATION` with `position: { ...target.position, width, height }` (x/y preserved). Mirrors the established `onCustomImageSizeChange` / `onDecorationPositionChange` split — position and size stay separate callbacks.

**Task 3 — Decoration `<Rnd>` resize + snap.** Replaced `enableResizing={false}` on the editable decoration `<Rnd>` with an 8-handle config (gated to non-locked decorations), added `resizeHandleStyles` (the 8×8 white-square handles), `lockAspectRatio={d.kind === 'icon'}`, an `onResizeStop` that commits size + position once per gesture, and snap wiring: `onDragStart` builds the snap index, a new `onDrag` runs `runSnapForDrag` (with Shift axis-constrain + multi-select bounds branch), and `onDragStop` does a final snap pass and clears the guide overlay. No renderer file touched — all handles/snap are `editable={true}` chrome.
