## What changed

### UI polish on /explore (`src/app/explore/`)

- **Tag pillset removed** — the row of #hooks #storytime #productivity etc.
  chips under the tabs is gone. (PILL_TAGS constant kept; still used for
  the no-search-match empty state.)
- **Tabs → filter dropdown** — Trending/New/Featured tab strip replaced
  with `<FilterButton />` on the right side of the search bar. New
  client component `filter-button.tsx` opens a popover with three rows
  (Trending / New / Featured + descriptions), updates `?tab=…` via
  `router.replace`, outside-click closes (wrapper-ref + mousedown pattern
  from `profile-menu.tsx`). Visual style matches the search box border/
  radius so they read as a single composite control.

  Dashboard icon; the link was redundant.
- **Header restructure** — title sits alone left-aligned; search +
  filter-button now share one flex row.

### Mock carousel seed for @diego

- **`src/app/api/admin/seed-explore/route.ts` (new)** — dev-only POST
  endpoint gated by `ADMIN_SEED_TOKEN` bearer token, refuses to run in
  `NODE_ENV=production`. Hand-crafted 12 carousels for diego (id
  `ed8ca688-…`), one per built-in template:
  bold-minimal / dark-gradient / soft-pastel / neon-pop / clean-serif /
  news-drop / news-cyan / highlight-bar / magazine / quote-card / y2k-pop
  / bold-yellow.
  Each carousel has 5–7 slides with distinct topics
  (productivity / sleep / finance / DSLR / travel / AI hot-takes / no-app
  productivity / stoicism / designer routine / quotes / 90s nostalgia /
  letter-to-younger-self) and 1–3 tags. Backgrounds use Pexels public
  URLs (no API key needed).
  - Uses the existing `buildSlideElement` → `next/og` `ImageResponse`
    pipeline to pre-render slide 1 to a 1080×1920 PNG.
  - Uploads each PNG to `hero-thumbnails/<diego>/<uuid>.png`.
  - Inserts directly into `published_carousels` via the admin client
    (bypassing the `publish_carousel` RPC because service-role auth.uid()
    is null) with a manually-generated slug + 5x retry on slug collision.
  - Refreshes `popularity_score` after seeding so the Trending tab orders
    correctly on first load.
- **Companion DELETE handler** — matches projects by the `[seed] ` title
  prefix, cascades to `published_carousels` via `source_project_id`, then
  removes the hero files via Storage API. Lets you reset the seed cleanly.
- **`src/middleware.ts`** — added a skip for `/api/admin/*` so the
  middleware doesn't redirect bearer-token-authed admin routes through
  Supabase session auth (mirrors the existing skip pattern for
  `/api/webhooks`, `/api/v1`, `/api/mcp`).

- `npx tsc --noEmit` passes (only pre-existing mcp-handler error)

  different — the visual variety is the point of the seed)

## Env

Add to `.env.local`:
```
ADMIN_SEED_TOKEN=<random-hex>
```

To run again:
```bash
# Reset:
curl -X DELETE -H "Authorization: Bearer $ADMIN_SEED_TOKEN" http://localhost:3000/api/admin/seed-explore
# Seed:
curl -X POST -H "Authorization: Bearer $ADMIN_SEED_TOKEN" http://localhost:3000/api/admin/seed-explore
```
