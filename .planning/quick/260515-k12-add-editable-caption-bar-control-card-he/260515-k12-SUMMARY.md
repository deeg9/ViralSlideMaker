## Decisions Made

- **No-override resolveCaptionBar branch reuses `bottomCardBackground` verbatim** (not `hexToRgba`): magazine-bold's `backgroundColor` is `#000000` (6-digit) and `bottomCardBackground` also handles the 8-digit-hex passthrough case — this keeps the legacy path byte-identical (TPLREND-05).
- **Sliders hold a local draft state** (`useState`) driving the range `<input>`: a controlled input bound only to the prop reverts mid-gesture in jsdom and would also lag in the browser. The draft is synced back to the resolved value via `useEffect` on external change (undo/redo/slide switch). This surfaced as a Task 2 test failure and was fixed in-flight (see Issues Encountered).
- **`onSlidePreview` falls back to `onSlideUpdate`** in `ElementsPanel` when the optional prop is absent — isolated unit tests that omit it still get a working card.
