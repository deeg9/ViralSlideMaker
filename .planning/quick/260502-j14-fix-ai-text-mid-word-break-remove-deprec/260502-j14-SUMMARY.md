# 260502-j14 — Mid-word break fix + font-size cap raise

Two quick paper-cut polishes shipped as one logical unit (both surfaced from the same screenshot pair).

## 1. Mid-word break fix (`cf8c082`)

**Symptom:** AI body/hook text wrapped mid-word on the slide canvas — `intellectu | al property,`, `creative owner | ship,` `newsle | tter.`, `AI a | nd music`. The right-rail textarea wrapped the same strings cleanly. Words that would've fit on the next line were broken at character boundaries instead.

**Root cause:** Three call sites (`resolve-overlay.ts:190` pill segments, `:213` plain segments, `slide-preview.tsx:436` hook container) set `wordBreak: 'break-word'`. Per MDN, `word-break: break-word` is a deprecated alias that browsers now interpret as `word-break: normal` + `overflow-wrap: anywhere`. The `anywhere` value breaks at any character even when there's room on the next line — exactly the symptom. The sibling `overflow-wrap: break-word` (already present everywhere) is the modern, correct rule that only breaks unbreakable strings.

**Fix:** Removed the three `wordBreak: 'break-word'` declarations. Kept `overflowWrap: 'break-word'` everywhere it was set. Replaced each removed line with a `quick-260502-j14:` comment so future readers don't reinstate it.

**Verification:** 215/215 tests pass. Live Playwright on the editor confirms text wraps cleanly at word boundaries on slide 7 of the test project.

## 2. Font-size cap raise (`dad1507`)

**Symptom:** Hook size slider in the active editor capped at 96, body at 56. Users couldn't push hooks large enough to take over the top half of the canvas for short, punchy headlines.

**Fix:** Bumped caps in `ActiveTextBoxCard.tsx:257` — hook 96 → 240, body 56 → 120. Body cap now matches the existing custom-text cap. Step stays at 2.

**Out of scope (deliberate):** the legacy editor (`text-editor-panel-legacy.tsx`, behind `NEXT_PUBLIC_NEW_TEXT_RAIL=false`) keeps its old caps. It's rollback safety; raising its caps too would muddy that role.

**Verification:** 88/88 editor tests pass. Live Playwright confirms the slider now drags to 240 and renders the hook at 200px cleanly.
