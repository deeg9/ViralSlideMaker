<objective>
Fix the regression where two AI-generated text boxes (e.g. hook + body, or HOOK + EXPOSED!) visually overlap in the freshly-generated slide preview. The user's concrete repro: "Copy Style" on a Meta-workers caption-bar-bottom reference produced a slide whose multi-line headline crashes down into the subtitle.

Purpose: Add a reactive overlap-prevention pass — after the AI generator places text boxes, measure their approximate heights, detect vertical overlaps, and push the lower box down until they don't collide. Reactive, additive, cheap; does not touch archetype semantics, manual snap-to-guide behavior, or slide-preview.tsx.

Output: A new pure helper `separateOverlappingTextBoxes` in `src/lib/editor/`, three covering unit tests, and two one-line wiring calls in the two AI carousel emit paths (`generate-slides.ts` for the topic flow, `generate-from-style-spec.ts` for the style-from-reference flow). Initial generation AND regenerate-from-references both hit one of these paths; the manual regenerate-text route only swaps strings (no position change) and is intentionally NOT wired.

    ```ts
    // Reference canvas = 1080 × 1920 (REF_WIDTH / REF_HEIGHT).
    // Sizes returned as PERCENT of canvas (matches TextBoxPosition convention).
    export interface EstimateHeightOptions {
      /** Reference canvas width in px. Default 1080. */
      canvasWidthPx?: number
      /** Reference canvas height in px. Default 1920. */
      canvasHeightPx?: number
      /** Fallback font size in px when textBox.font_size is undefined. Default 64. */
      defaultFontSizePx?: number
      /** Line-height multiplier. Default 1.2 (tight, matches our renderer baseline). */
      lineHeight?: number
      /** Avg char width as fraction of font_size. Default 0.55 (sans-serif median). */
      avgCharWidthFactor?: number
    }
    export function estimateTextBoxHeightPct(
      textBox: TextBox,
      options?: EstimateHeightOptions,
    ): number

    export interface SeparateOverlappingOptions extends EstimateHeightOptions {
      /** Padding (canvas-% units) inserted BETWEEN boxes after separation. Default 1 (≈19px). */
      gapPct?: number
      /** Max bottom edge in canvas-%. Boxes overflowing past this are clamped at the bottom; in that case earlier boxes are NOT shifted up (we accept the worst-case overflow rather than re-layout). Default 100. */
      maxYPct?: number
    }

    /**
     * Reactive collision pass. Pure.
     *
     * For each pair of TEXT BOXES whose anchor='custom' (after the
     * structural-to-custom normalization below), if their estimated rects
     * overlap vertically, push the LOWER box (higher y%) downward so its
     * top equals the upper box's bottom + gapPct.
     *
     * STRUCTURAL-ANCHOR NORMALIZATION (single-pass, applies when
     * hook + body share a non-'custom' anchor, which is the Meta-workers
     * repro case): synthesize x/y/width from canonical defaults — hook lands
     * in the upper third for anchor='top', upper-middle for 'center', and
     * approx y=70 for 'bottom'; body sits directly under hook with default
     * widths matching the renderer (60% width, centered → x=20). Only the
     * two structural roles ('hook' and 'body') are normalized; 'custom' role
     * boxes that already carry a 'top'|'center'|'bottom' anchor are left
     * alone (per Phase 60 doc in snap-index.ts — those need DOM measurement).
     *
     * Returns a NEW array; never mutates input. TextBoxes with anchor !==
     * 'custom' (and not picked up by the structural normalization) are
     * passed through unchanged.
     */
    export function separateOverlappingTextBoxes(
      textBoxes: TextBox[],
      options?: SeparateOverlappingOptions,
    ): TextBox[]
    ```

    Height estimation algorithm (pure, no DOM):
      const fontSizePx = textBox.font_size ?? defaultFontSizePx
      const widthPx    = ((textBox.position.width ?? 60) / 100) * canvasWidthPx
      const avgCharPx  = fontSizePx * avgCharWidthFactor    // ≈0.55 × font_size
      const charsPerLine = Math.max(1, Math.floor(widthPx / avgCharPx))
      const text         = textBox.text ?? ''
      // Split on existing newlines first; for each segment, wrap by chars.
      const lines = text
        .split('\n')
        .reduce((acc, segment) => acc + Math.max(1, Math.ceil(segment.length / charsPerLine)), 0)
      const heightPx = lines * fontSizePx * lineHeight
      return (heightPx / canvasHeightPx) * 100

    Separation algorithm (deterministic):
      1. Build augmented entries { box, top, bottom } for boxes participating in
         layout (custom anchor OR normalized structural hook/body). Skip the rest.
      2. Sort by top ascending; tie-break by hook-before-body-before-custom role.
      3. Iterate in order; track cursor = previousBottom + gapPct (default 1).
         If currentTop < cursor → shift currentTop = cursor (and bottom += delta).
         If currentBottom > maxYPct → clamp bottom = maxYPct (overflow accepted).
      4. Reassemble: replace box.position with the new custom-anchor (x, y, width).
