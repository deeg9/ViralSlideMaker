<objective>
Upgrade the project's Gemini TEXT model from `gemini-2.5-flash` to `gemini-3-flash-preview` (Google's official recommended replacement for 2.5 Flash, which sunsets 2026-10-16).

The model ID is currently duplicated as a hardcoded string literal across ~11 production files. This plan centralizes it into a single env-backed source-of-truth constant, flips every text-model call site to import it, adds a SQL migration for the `style_spec_cache.model` column default, and updates the affected test fixtures.

Purpose: Get ahead of the 2.5 Flash deprecation while killing the duplicated-literal maintenance hazard. The env-var fallback makes rollback off a preview-status model a zero-deploy change.

Output:
- New `src/lib/ai/gemini-model.ts` exporting `GEMINI_TEXT_MODEL` (env-backed).
- 11 production call sites importing the constant; zero hardcoded `gemini-2.5-flash` text literals left.
- New SQL migration `20260515_v213_style_spec_cache_default_gemini3.sql`.
- Updated test fixtures + a new constant-resolution test + a grep-gate test.
</objective>

<stale-cache-decision>
DECISION (documented per constraints): `lookupStyleSpec` in `style-spec-cache.ts`
filters cached rows ONLY by `style_spec.schema_version === STYLE_SPEC_VERSION` (the
Phase 80 R5 defensive filter). It does NOT filter by the `model` column, and this
plan does NOT add a model filter.

Rationale: a cached `StyleSpec` is model-agnostic validated JSON — it is the OUTPUT
of the two-phase firewall (closed-enum-coerced, Zod-validated). It carries no
model-specific representation. A 2.5-Flash-era cache row served to a 3-Flash-era
request is a correct, already-validated StyleSpec; serving it is the intended $0-cost
cache hit, not a bug. The `model` column is provenance/analytics metadata, not a
cache-key partition. Old rows naturally age via the existing retention story.
Adding a model filter would needlessly invalidate every pre-upgrade cache entry and
force paid re-extractions — that is over-engineering. No code change to
`lookupStyleSpec`.
</stale-cache-decision>
