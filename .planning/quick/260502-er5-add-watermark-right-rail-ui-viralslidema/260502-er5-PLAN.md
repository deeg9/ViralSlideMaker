# Plan: Watermark right-rail UI

## Goal

Add a per-slide Watermark section to the editor right rail with tier-aware behavior:
- **Free tier:** ViralSlideMaker watermark always ON, toggle locked, custom upload locked. Pro upgrade chip + hint visible.
- **Paid tier (plus/pro):** Toggle functional (default OFF — current `resolveForcedWatermark` returns null for non-free). Custom logo upload + position picker (bottom-left / bottom-right) available.

Replicates the Canva/CapCut UX pattern of free-tier branded watermark as primary upgrade hook.
