## End-to-End Flow

The user-facing flow shipped in this milestone:

1. User opens a project's editor.
2. User clicks a text box (hook, body, or custom) on the canvas → selection ring appears.
3. User drags a side handle → box width changes; font unchanged. (v2.8 muscle memory preserved.)
4. User drags a corner handle → box width AND font size scale together by the same ratio. Past the cap, box keeps growing while font stops at 240 (hook) / 120 (body).
5. User holds Shift while dragging a corner → font does NOT scale; corner behaves as width-only escape.
6. Right-rail font-size slider settles on the new value within 1 frame of `onResizeStop`.
7. User presses Cmd+Z → entire gesture (potentially 60+ pointer ticks) reverts in ONE undo step.
8. ZIP download / Satori PNG export of the slide produces the same visual output as the editor preview (TPLREND-05 byte-identity).
